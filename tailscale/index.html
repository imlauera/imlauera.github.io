Tailscale

VPN mesh (como Hamachi) de configuración automática, peer-to-peer.

Identificación

  • El software era Tailscale (empezaba con “t”).
  • Alternativas similares: tinc, Tungle, ZeroTier.

Instalación en Arch Linux

sudo pacman -S tailscale
sudo systemctl enable --now tailscaled
sudo tailscale up
  • tailscaled.service es el daemon de Tailscale.
  • tailscale up abre la autenticación en el navegador.
  • Al final quedás con una IP de Tailscale (100.x.y.z) para comunicarte con otros dispositivos en la misma red VPN (ej. el celular).

Uso con Android desde Linux (adb)

  • El Android de Tailscale incluye una CLI escondida.
  • Para usarla: activar Developer options dentro de la app (Ajustes del Android de Tailscale).
  • Desde Linux: adb shell para correr el comando tailscale.
  • Permite autenticarse, conectar/desconectar, ver estado, etc., sin tocar la pantalla del celular.

Nota

  • Android: se puede instalar el APK de Shell Box Argentina desde Linux.
  • iPhone: solo desde la App Store.
