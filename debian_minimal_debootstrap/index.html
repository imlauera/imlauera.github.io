Adapté mi guía de instalación básica de Arch a Debian. La idea es la misma: particionar, formatear, instalar lo mínimo a mano, configurar fstab, locale, hostname y GRUB, sin instalador gráfico.

La diferencia es que en vez de pacstrap se usa debootstrap. Lo hice desde un Arch ya arrancado (también funciona desde el live ISO de Arch).

Esquema de particiones

Ojo con esto: en la guía de Arch sda2 es swap y sda3 es el root. En esta máquina es al revés:

Partición Uso Formato
/dev/sda1 EFI (1G) FAT32
/dev/sda2 rootfs (359G) ext4
/dev/sda3 swap (8G) swap
/dev/sda4 Arch actual (/) no se toca
/dev/sda5 EFI del Arch actual no se toca

Advertencia: en sda2 había una instalación vieja de Gentoo con su /home y sus configuraciones. Formatear la partición la borra toda. Confirmá antes de apretar enter.

1. Preparación

loadkeys es
timedatectl set-ntp true

pacman -S debootstrap debian-archive-keyring

Si no instalás debian-archive-keyring, debootstrap avisa Cannot check Release signature; keyring file not available pero igual termina. Mejor instalarlo.

2. Desmontar, formatear y montar

Primero hay que desmontar lo que esté colgado en sda2 (en mi caso /mnt/gentooo):

umount /mnt/gentooo

mkfs.fat -F32 /dev/sda1
mkfs.ext4 -F /dev/sda2
mkswap /dev/sda3
swapon /dev/sda3

mount /dev/sda2 /mnt
mkdir -p /mnt/boot/efi
mount /dev/sda1 /mnt/boot/efi

Verificá con lsblk que /mnt y /mnt/boot/efi estén montados en las particiónes correctas antes de seguir.

3. Bootstrap

debootstrap --arch amd64 stable /mnt http://deb.debian.org/debian

stable al momento de escribir esto es Debian 13 (trixie). Si querés bookworm: debootstrap --arch amd64 bookworm /mnt http://deb.debian.org/debian.

Esto baja ~100 MB y deja un sistema base mínimo. Es el equivalente a pacstrap -K /mnt base base-devel linux linux-firmware vim man-pages man-db.

4. fstab

A diferencia de Arch, acá no hay genfstab; se escribe a mano. Saco los UUID:

blkid -s UUID -o value /dev/sda1 /dev/sda2 /dev/sda3

Y escribo /mnt/etc/fstab (reemplazá los UUID por los tuyos):

# <file system> <mount point> <type> <options> <dump> <pass>
# /dev/sda2 -- rootfs
UUID=4639aa81-aa9f-4bb3-a2ec-37d4d8545584  /           ext4    defaults,noatime  0 1
# /dev/sda1 -- EFI
UUID=2E57-9597                              /boot/efi   vfat    umask=0077        0 2
# /dev/sda3 -- swap
UUID=6b73aa72-e5b1-473f-9db5-dbcdfca28cbc  none        swap    sw                0 0

5. Configuración dentro del chroot

En vez de ir escribiendo comando por comando, dejo un script y lo ejecuto con arch-chroot:

cp debian_setup.sh /mnt/
chmod +x /mnt/debian_setup.sh
arch-chroot /mnt /bin/bash /debian_setup.sh

El script hace esto:

#!/bin/bash
set -e
export DEBIAN_FRONTEND=noninteractive
# IMPORTANTE: ver el gotcha del PATH más abajo
export PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

# repositorios: stable + updates + security
cat > /etc/apt/sources.list <<'EOF'
deb http://deb.debian.org/debian stable main
deb http://deb.debian.org/debian stable-updates main
deb http://deb.debian.org/debian-security stable-security main
EOF
apt-get update

# zona horaria (igual que la guía de Arch)
ln -sf /usr/share/zoneinfo/America/Buenos_Aires /etc/localtime
echo 'America/Buenos_Aires' > /etc/timezone
dpkg-reconfigure -f noninteractive tzdata

# idioma y teclado español (equivalente a KEYMAP=es)
apt-get install -y --no-install-recommends locales console-setup
sed -i 's/^# *en_US.UTF-8 UTF-8/en_US.UTF-8 UTF-8/' /etc/locale.gen
sed -i 's/^# *es_AR.UTF-8 UTF-8/es_AR.UTF-8 UTF-8/' /etc/locale.gen
locale-gen
echo 'LANG=en_US.UTF-8' > /etc/default/locale
cat > /etc/default/keyboard <<'EOF'
XKBMODEL="pc105"
XKBLAYOUT="es"
XKBVARIANT=""
XKBOPTIONS=""
BACKSPACE="guess"
EOF

# hostname y hosts
echo 'debian' > /etc/hostname
cat > /etc/hosts <<'EOF'
127.0.0.1       localhost
::1             localhost ip6-localhost ip6-loopback
ff02::1         ip6-allnodes
ff02::2         ip6-allrouters
127.0.1.1       debian.localdomain      debian
EOF

# DNS de Google; NetworkManager no lo pisa
mkdir -p /etc/NetworkManager/conf.d
printf '[main]\ndns=none\n' > /etc/NetworkManager/conf.d/99-dns.conf

# contraseñas TEMPORALES: cambiarlas después del primer boot
echo 'root:debian' | chpasswd
useradd -m -G sudo,audio,video esotericwarfare
echo 'esotericwarfare:debian' | chpasswd

# sistema mínimo
apt-get install -y --no-install-recommends \
    linux-image-amd64 \
    grub-efi-amd64 \
    dosfstools \
    network-manager \
    sudo \
    vim \
    man-db \
    bash-completion \
    firmware-linux \ 
    efibootmgr \
    os-prober 

systemctl enable NetworkManager

# GRUB en /dev/sda1, con entrada propia y fallback removable
grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=debian --recheck /dev/sda
grub-install --target=x86_64-efi --efi-directory=/boot/efi --removable --recheck /dev/sda
sudo grub-install --target=x86_64-efi --efi-directory=/boot --removable   
update-grub # # equivale a grub-mkconfig -o /boot/grub/grub.cfg

Quedó el kernel 6.12.117+deb13-amd64, el initrd y tres entradas en grub.cfg: Debian, Debian recovery y UEFI Firmware Settings.

6. El DNS hay que escribirlo desde fuera del chroot

arch-chroot bind-mounta el /etc/resolv.conf del host dentro del chroot, así que escribir desde adentro pisa el archivo del host (y si usás Tailscale, su resolvedor lo vuelve a sobrescribir). Después de salir del chroot:

printf 'nameserver 8.8.8.8\nnameserver 8.8.4.4\n' | sudo tee /mnt/etc/resolv.conf

7. Reiniciar

No reinicié enseguida porque estaba trabajando desde ese mismo sistema, pero llega un momento:

exit
umount /mnt/boot/efi
umount /mnt
reboot

Al bootear, efibootmgr ya había creado la entrada debian apuntando a sda1 y la puso primera en el BootOrder:

Boot0002* debian  HD(1,GPT,...)/\EFI\debian\grubx64.efi
BootOrder: 0002,0001,2001,2002,2003

Si tu UEFI es de los que pierden la entrada, el --removable de arriba dejó también /boot/efi/EFI/BOOT/BOOTX64.EFI como respaldo.

Después del primer boot:

nmtui              # para conectarse al wifi
passwd             # cambiar la contraseña temporal de root
sudo apt update && sudo apt upgrade

Gotchas que me encontré

  1. PATH dentro del chroot. arch-chroot /mnt /bin/bash me dejó PATH=/usr/local/sbin:/usr/local/bin:/usr/bin, sin /usr/sbin. dpkg-reconfigure, useradd, locale-gen, grub-install y update-grub viven en /usr/sbin, así que el primer intento murió con dpkg-reconfigure: command not found. Poné el export PATH=... al principio del script.

  2. resolv.conf bind-mountado, explicado arriba. Además, chattr +i sobre ese archivo dentro del chroot no queda (no se puede poner el flag immutable).

  3. El swap viejo. mkswap avisa wiping old swap signature; es normal. El Arch actual usa un swapfile, así que sda3 estaba libre para usarla.

  4. Entradas EFI viejas. Quedó la entrada Gentoo en efibootmgr apuntando a sda1 aunque ya no exista. Es inofensiva; si querés limpiarla: efibootmgr -b 0000 -B.

Como la guía original terminaba con el cheatsheet de pacman, acá va el equivalente:

Esta instalacion es similar pero no la probe.

Debian con debootstrap, versión actualizada

Tomé tu guía de Arch y adapté todo lo que tiene equivalente en Debian. Asumo UEFI, disco /dev/sda y Debian 13 (trixie).

1. Desde el live USB

sudo -i
loadkeys es
timedatectl set-ntp true

# WiFi (el live de Debian usa NetworkManager, no iwd)
nmcli device wifi list
nmcli device wifi connect "SSID" password "clave"
ping -c3 deb.debian.org

apt update
apt install debootstrap arch-install-scripts gdisk

2. Particiones (EFI 300M + swap 4G + root)

fdisk -l
sfdisk /dev/sda <<EOF
label: gpt
,300M,U
,4G,S
,,L
EOF

Esto borra el disco. Si preferís hacerlo a mano, usá cfdisk /dev/sda o fdisk /dev/sda.

3. Formatear y montar

mkfs.fat -F32 /dev/sda1
mkswap /dev/sda2
mkfs.ext4 /dev/sda3

mount /dev/sda3 /mnt
mkdir -p /mnt/boot/efi
mount /dev/sda1 /mnt/boot/efi
swapon /dev/sda2

4. Sistema base

debootstrap --arch amd64 --components=main,contrib,non-free-firmware \
  --include=locales,console-setup,keyboard-configuration,network-manager,sudo,vim,bash-completion \
  trixie /mnt http://deb.debian.org/debian

5. fstab y chroot

genfstab -U /mnt >> /mnt/etc/fstab
cat /mnt/etc/fstab        # verificá root, swap y EFI
arch-chroot /mnt

6. Configuración dentro del chroot

Repos, kernel y bootloader:

cat > /etc/apt/sources.list <<EOF
deb http://deb.debian.org/debian trixie main contrib non-free-firmware
deb http://deb.debian.org/debian trixie-updates main contrib non-free-firmware
deb http://security.debian.org/debian-security trixie-security main contrib non-free-firmware
EOF

apt update
apt install linux-image-amd64 firmware-linux grub-efi-amd64 efibootmgr os-prober dosfstools

En Debian dejá efibootmgr instalado: grub-install lo usa para registrar la entrada de arranque en la NVRAM.

Hora e idioma:

ln -sf /usr/share/zoneinfo/America/Argentina/Buenos_Aires /etc/localtime
hwclock --systohc

sed -i 's/^# *en_US.UTF-8/en_US.UTF-8/' /etc/locale.gen
locale-gen
update-locale LANG=en_US.UTF-8

Teclado y fuente de consola (Debian no usa vconsole.conf):

cat > /etc/default/keyboard <<EOF
XKBMODEL="pc105"
XKBLAYOUT="es"
XKBVARIANT=""
XKBOPTIONS=""
EOF

sed -i 's/^FONTFACE=.*/FONTFACE="Terminus"/; s/^FONTSIZE=.*/FONTSIZE="16x32"/' /etc/default/console-setup

Hostname y hosts:

echo "debian" > /etc/hostname
cat > /etc/hosts <<EOF
127.0.0.1   localhost
127.0.1.1   debian.localdomain debian
::1         localhost ip6-localhost ip6-loopback
EOF

Usuarios (el grupo wheel de Arch es sudo acá, y uucp es dialout):

passwd
useradd -m -G sudo,audio,video,dialout -s /bin/bash tuusuario
passwd tuusuario

7. GRUB

grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=Debian --recheck

Si tu UEFI es de los que borran la entrada solos, agregá --force-extra-removable (o usá --removable) para instalar también en la ruta de respaldo.

Para que os-prober detecte Windows u otras distros, editá /etc/default/grub y agregá GRUB_DISABLE_OS_PROBER=false. Montá las otras particiones y generá la config con:

update-grub        # equivale a grub-mkconfig -o /boot/grub/grub.cfg

8. Salir y reiniciar

exit
umount -R /mnt
reboot

Después del primer arranque

Red y DNS. Con nmtui te conectás al WiFi. Para las DNS no uses chattr +i sobre resolv.conf, hacelo por NetworkManager:

nmcli connection show
sudo nmcli connection modify "NOMBRE" ipv4.dns "9.9.9.11 149.112.112.11" ipv4.ignore-auto-dns yes
sudo nmcli connection down "NOMBRE" && sudo nmcli connection up "NOMBRE"

Paquetes de tu lista, traducidos a Debian:

sudo apt install openssh-server fzf tmux fastfetch fish sway foot wl-clipboard grim \
  btop imv mpv yt-dlp imagemagick git rsync w3m links irssi neomutt isync msmtp pass \
  notmuch lynx tor torsocks zip unzip wget curl plocate apt-file tldr bluez fbi \
  pipewire pipewire-pulse pipewire-alsa wireplumber xdg-desktop-portal-wlr xwayland
# Opcionales: firefox-esr chromium thunderbird telegram-desktop libreoffice
#             obs-studio gimp kdenlive qbittorrent-nox virt-manager

Los archivos /etc/mpv/mpv.conf y /etc/yt-dlp.conf funcionan igual, solo copialos.

Lo que en Arch hacés a mano y en Debian ya viene (o casi):

Tema En Debian
fsck al inicio El initramfs ya lo hace. Verificá que root tenga 1 en el pass de /etc/fstab. Para forzarlo, agregá fsck.mode=force fsck.repair=preen a GRUB_CMDLINE_LINUX_DEFAULT y corré update-grub.
Microcódigo sudo apt install intel-microcode (o amd64-microcode)
TRIM para SSD fstrim.timer ya viene activo
Journal persistente Normalmente ya lo es. Chequeá con ls /var/log/journal.
/tmp en RAM Trixie ya lo monta como tmpfs
AppArmor sudo apt install apparmor apparmor-utils apparmor-profiles y verificá con sudo aa-status. El kernel de Debian ya lo trae activado.
Firewall sudo apt install ufw && sudo ufw enable
zram sudo apt install systemd-zram-generator y la misma config de /etc/systemd/zram-generator.conf de tu guía. Es alternativa a la swap en disco.
Snapshots sudo apt install timeshift (o snapper)
Swappiness echo 'vm.swappiness=10' | sudo tee /etc/sysctl.d/99-swappiness.conf
Mirrors No hace falta reflector: deb.debian.org es un CDN

Cheatsheet pacman → apt:

pacman apt
pacman -Syu apt update && apt full-upgrade
pacman -S pkg apt install pkg
pacman -Rns pkg apt purge pkg && apt autoremove
pacman -Ss texto apt search texto
pacman -Si pkg apt show pkg
pacman -Ql pkg dpkg -L pkg
pacman -Qe apt-mark showmanual
pacman -Qdt apt autoremove --dry-run
pacman -Scc apt clean
pkgfile apt-file search archivo

El AUR no existe en Debian. Para lo que sacabas de ahí (freetube, tor-browser, etc.) usá Flatpak, .deb oficiales, o compilá desde el repo.
