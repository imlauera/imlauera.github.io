Leer en voz alta (navegador)

Listo para leer.

Usa la voz del navegador (Web Speech API). Para descargar MP3, usá el reproductor/descarga cuando esté disponible.

yay -Sc --aur
yay -Scc
sudo paccache -rk1

Alias para Simplificar: Si prefieres que yay siempre limpie solo la caché de AUR, puedes crear un alias en tu archivo .bashrc o .zshrc: bash

alias yay='yay --aur'
