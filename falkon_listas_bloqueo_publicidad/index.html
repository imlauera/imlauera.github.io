Bloquear publicidad en Falkon: todas las listas que uso

2026-11-12 · falkon, ads, adblock

Descargar MP3 · Ver en Internet Archive

Falkon (basado en QtWebEngine/Chromium) trae un bloqueador de publicidad integrado, sin extensiones. El problema es que por defecto solo activa dos listas (EasyList y NoCoin), y con eso muchos sitios siguen mostrando anuncios. Acá dejo el conjunto completo de listas que tengo cargadas, cómo se instalan y cuáles son las limitaciones reales del motor.

Por qué el AdBlock de Falkon y no uBlock Origin

Falkon no soporta WebExtensions, así que no podés instalar uBlock Origin. Lo que sí tiene es una implementación propia compatible con la sintaxis de Adblock Plus (AdBlockRule), con soporte de:

  • bloqueo por red (||dominio^, $third-party, $script, $image, etc.)
  • ocultamiento cosmético clásico (##.selector, dominio##.selector)
  • excepciones (@@) y listas de dominios por $domain=

No soporta las extensiones modernas de uBlock (scriptlets ##+js(...), $redirect, filtros cosméticos procedurales). Por eso las listas pensadas para uBlock funcionan parcialmente: se aplica todo lo que es red y cosmético clásico, y se ignora lo específico de uBO.

Dónde guarda las listas y cómo las carga

Todo vive en el perfil activo:

~/.config/falkon/profiles/default/adblock/

Al arrancar, Falkon lee automáticamente todos los *.txt de esa carpeta y crea una suscripción por archivo (excepto customlist.txt, que son las “Custom Rules” editables). Cada archivo tiene que empezar exactamente así:

Title: Nombre de la lista
Url: https://url-de-la-lista.txt
[Adblock Plus 2.0]
...reglas...

La línea 3 debe empezar con [Adblock, si no Falkon considera el archivo inválido y trata de re-descargarlo. La segunda línea (Url:) es la que usa para actualizar la lista cada tanto.

Cómo agregar una lista

Opción 1: por la interfaz

Configuración → AdBlock → Add Subscription y pegás el nombre y la URL. Falkon crea el .txt, lo descarga y lo deja activo (esto sí funciona en caliente, sin reiniciar).

Opción 2: a mano (varias de una vez)

Como Falkon lee todos los .txt, podés descargarlas vos y escribirles la cabecera. Este script hace exactamente eso: descarga, verifica que empiece con [Adblock (si no, le inserta la cabecera) y guarda el archivo:

#!/usr/bin/env bash
set -u
DIR="$HOME/.config/falkon/profiles/default/adblock"
mkdir -p "$DIR"

add_list() {
    local file="$1" title="$2" url="$3"
    local tmp; tmp="$(mktemp)"
    curl -sSL --fail --max-time 90 -o "$tmp" "$url" || { echo "FALLÓ: $file"; return 1; }
    {
        printf 'Title: %s\n' "$title"
        printf 'Url: %s\n' "$url"
        head -1 "$tmp" | grep -q '^\[Adblock' \
            && cat "$tmp" \
            || { printf '[Adblock Plus 2.0]\n'; cat "$tmp"; }
    } > "$DIR/$file"
    [ -n "$(tail -c1 "$DIR/$file")" ] && printf '\n' >> "$DIR/$file"
    rm -f "$tmp"
    echo "OK: $file"
}

add_list "peterlowe.txt" "Peter Lowe's Ad and tracking server list" \
    "https://pgl.yoyo.org/adservers/serverlist.php?hostformat=adblockplus&showintro=0&mimetype=plaintext"
add_list "easylistspanish.txt" "EasyList Spanish" \
    "https://easylist-downloads.adblockplus.org/easylistspanish.txt"
add_list "antiadblockfilters.txt" "Adblock Warning Removal List" \
    "https://easylist-downloads.adblockplus.org/antiadblockfilters.txt"
add_list "fanboy-annoyance.txt" "Fanboy's Annoyance List" \
    "https://easylist-downloads.adblockplus.org/fanboy-annoyance.txt"
add_list "fanboy-social.txt" "Fanboy's Social Blocking List" \
    "https://easylist-downloads.adblockplus.org/fanboy-social.txt"
add_list "easylist-cookie.txt" "EasyList Cookie List" \
    "https://secure.fanboy.co.nz/fanboy-cookiemonster.txt"
add_list "ublock-badware.txt" "uBlock filters - Badware risks" \
    "https://raw.githubusercontent.com/uBlockOrigin/uAssets/master/filters/badware.txt"
add_list "ublock-resource-abuse.txt" "uBlock filters - Resource abuse" \
    "https://raw.githubusercontent.com/uBlockOrigin/uAssets/master/filters/resource-abuse.txt"

Guardalo como add_adblock_lists.sh, chmod +x y ejecutalo. Después reiniciá Falkon para que las cargue.

Reiniciar es obligatorio

Esto es la parte que más confunde: Falkon solo lee las listas al arrancar. Si agregás archivos .txt con Falkon abierto, no se aplican hasta que lo cierres y lo vuelvas a abrir. La opción 1 (interfaz) sí es en caliente porque Falkon mismo registra la suscripción.

Para verificar que quedaron bien, después de reiniciar:

cd ~/.config/falkon/profiles/default/adblock
for f in *.txt; do
    printf '%-28s %s\n' "$f" "$(sed -n '3p' "$f")"
done

Todas las líneas 3 tienen que empezar con [Adblock. Y en la interfaz, Configuración → AdBlock debería listar las 13 suscripciones + Custom Rules.

Actualización automática

Falkon actualiza las suscripciones cuando pasaron más de 5 días desde el último chequeo (lastUpdate en settings.ini), o cuando apretás Update Subscriptions en el diálogo de AdBlock. Ojo: las listas de uBlock (Badware/Resource abuse) no empiezan con [Adblock, así que Falkon no puede auto-actualizarlas (el chequeo de descarga exige que el archivo empiece con [Adblock). Cargan bien, pero para actualizarlas hay que volver a correr el script.

Limitaciones que tenés que conocer

  • Anuncios de primera parte (first-party): si el sitio sirve los anuncios desde su propio dominio, ninguna lista de bloqueo los va a tocar. Esto es común en sitios de streaming o de noticias. Ahí la solución es a nivel DNS (Pi-hole / AdGuard Home) o directamente no hay atajo.
  • Sintaxis uBlock: las listas de uBlock se aplican solo en la parte compatible con Adblock Plus.
  • Anti-adblock: algunos sitios detectan el bloqueo y no cargan el contenido. Para eso está justamente Adblock Warning Removal List.

Cómo comprobar que bloquea

Con Falkon reabierto, entrá a:

  • https://d3ward.github.io/toolz/adblock.html
  • https://adblock-tester.com/

Si el puntaje es alto, las listas están activas. Si sigue bajo, revisá que Configuración → AdBlock tenga el bloqueo habilitado y que el sitio no esté en la whitelist.

Reglas propias y whitelist

En customlist.txt (Custom Rules) podés agregar lo que quieras. Ejemplos:

! Desbloquear un sitio entero
@@||misitio.com^$document

! Ocultar un div puntual
misitio.com##.banner-publicidad

! Bloquear un dominio a mano
||ads.ejemplo.com^

Con este conjunto, Falkon pasa de bloquear “algo” a bloquear en serio. La clave es entender que el motor es Adblock Plus clásico, que hay que reiniciar para cargar listas nuevas, y que los anuncios servidos desde el mismo dominio no los para nadie con listas.
