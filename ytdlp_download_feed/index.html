Yt-dlp descargar automáticamente todos los videos de tu feed sin acceder a Google, en baja calidad.

2026-08-27 · ytdlp

Uso opencli tenes que instalar eso y loguearte en tu cuenta de YouTube con chromium. opencli youtube login creo que era.

youtube-feed-play.sh

#!/bin/bash
mapfile -t urls < <(grep -oE 'https://www\.youtube\.com/watch\?v=[A-Za-z0-9_-]+' | sort -u)
mkdir -p /mnt/arch/ytdlp
for url in "${urls[@]}"; do
  yt-dlp --no-overwrites --match-filter '!is_live' \
    -f 'worstvideo+(wa[format_note*=original]/wa)/worst' \
    --merge-output-format mkv \
    -o '/mnt/arch/ytdlp/%(title)s [%(id)s].%(ext)s' "$url" &
done
wait

.bashrc:

alias ytfeed='opencli youtube feed | ~/youtube-feed-play.sh'

# Chromium headless en Xvfb para opencli
chrome-cli() {
  pkill -9 chromium 2>/dev/null
  pkill -9 Xvfb 2>/dev/null
  rm -f "$HOME/chrome-debug-profile/SingletonLock"
  local EXT_PATH="$HOME/Downloads/opencli-extension"
  xvfb-run --auto-servernum chromium \
    --remote-debugging-port=9222 \
    --disable-extensions-except="$EXT_PATH" \
    --load-extension="$EXT_PATH" \
    --remote-allow-origins="*" &
  sleep 3
  export OPENCLI_CDP_ENDPOINT="http://127.0.0.1:9222"
  echo "CDP endpoint: $OPENCLI_CDP_ENDPOINT"
}

Para descargar videos:

for i in $(seq 1 10) ; do ytfeed ; done
