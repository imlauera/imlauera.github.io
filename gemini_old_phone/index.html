installing Gemini on Old Phone

2026-10-24 · gemini

Baja ReOldAI y gemini lite y agrega la API key

1.2 — Crear la API key

  1. Entrá a console.cloud.google.com/apis/credentials.
  2. Tocá Crear credenciales → API key.
  3. Se genera una key que empieza con AIza.... Copiala y guardala en un lugar seguro.

1.3 — Restringir la key (recomendado)

  1. Hacé clic en el nombre de la key recién creada.
  2. En API restrictions, elegí Select API restrictions.
  3. En el buscador, escribí “Gemini” y seleccioná Gemini API.
  4. Tocá Guardar.

🔒 Seguridad: No compartas tu API key en público. Si la exponés, revocala desde la misma página de Credenciales.
