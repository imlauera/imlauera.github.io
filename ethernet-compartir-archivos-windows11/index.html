Resumen: Conectar 2 computadoras con cable Ethernet y compartir archivos

(Funciona solo entre computadoras con Windows. No necesita router ni internet.)

1. Conexión física

Conectá un cable Ethernet (LAN) entre los puertos de ambas computadoras.

2. Configurar IP estática en la PC 1

  1. Buscá “Conexiones de red” en el buscador de Windows.
  2. Clic derecho en el adaptador Ethernet → Propiedades.
  3. Seleccioná Protocolo de Internet versión 4 (TCP/IPv4) → Propiedades.
  4. Marcá “Usar la siguiente dirección IP” y completá:
    • IP: 192.168.1.100
    • Máscara de subred: se completa sola (255.255.255.0)
    • Puerta de enlace: dejala en blanco (o poné la misma IP)
  5. Aceptar para guardar.

3. Configurar IP estática en la PC 2

Mismos pasos, pero con:

  • IP: 192.168.1.101
  • Puerta de enlace: la IP de la primera PC (192.168.1.100)

4. Activar el uso compartido de red (en las dos PC)

Ir a Configuración de red e Internet → Centro de redes y recursos compartidos → Cambiar configuración de uso compartido avanzado, y:

  • Activar detección de redes (en redes privadas y públicas).
  • Activar uso compartido de archivos e impresoras.
  • Activar uso compartido de la carpeta pública.
  • Desactivar el uso compartido protegido con contraseña (para que sea más fácil acceder).

5. Compartir una carpeta (en la PC 1)

  1. Creá o elegí la carpeta que querés compartir.
  2. Clic derecho → Dar acceso a → Personas específicas.
  3. Elegí Todos (Everyone), clic en Agregar y poné el permiso Lectura y escritura.
  4. Clic en Compartir y anotá la ruta de red que aparece.
  5. Otra vez clic derecho en la carpeta → Propiedades → pestaña Compartir → Uso compartido avanzado.
  6. Marcá “Compartir esta carpeta” → Permisos → permitir Control total → Aplicar.

6. Acceder desde la PC 2

  1. Abrí el Explorador de archivos.
  2. En la barra de direcciones escribí: \\192.168.1.100\NombreDeLaCarpeta
  3. Presioná Enter y se abre la carpeta compartida.
  4. Copiá y pegá archivos entre las dos computadoras.

Notas importantes

  • Solo funciona entre computadoras Windows. Con Mac o Linux hay que usar otros métodos.
  • Para archivos grandes, la velocidad del cable Ethernet es mejor que la del Wi-Fi.
