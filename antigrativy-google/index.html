Google Antigravity CLI: mi alternativa favorita

Plan gratuito

Agente autónomo de terminal

Google reemplazó el acceso gratuito individual de Gemini CLI por Antigravity CLI el 18 de junio de 2026. Es importante porque muchos tutoriales todavía recomiendan el viejo Gemini CLI.

image

GitHub+1

Antigravity permite ejecutar tareas de programación y utilizar herramientas desde la terminal, con un plan de $0 y cuotas limitadas.

En Arch Linux:

curl -fsSL https://antigravity.google/cli/install.sh -o /tmp/agy-install.sh
less /tmp/agy-install.sh
bash /tmp/agy-install.sh

Luego:

~/.local/bin/agy

Te pedirá iniciar sesión con Google. Es una alternativa genuina a Claude Code, aunque necesita autenticación y está sujeta a límites gratuitos.

3. GitHub Copilot CLI: otro agente gratuito

GitHub ofrece Copilot CLI en su plan Free. Puede modificar archivos, ejecutar herramientas y trabajar autónomamente sobre proyectos.

Instalación:

npm install -g @github/copilot
copilot

Dentro de Copilot escribí /login para autenticarte.

Tiene créditos gratuitos mensuales y funciona directamente en Linux. Su inconveniente es que la cuota también se termina.

4. OpenRouter: más modelos sin pagar

OpenRouter tiene modelos gratuitos que podés conectar a OpenCode utilizando una API key.

Su límite gratuito normal es de 50 solicitudes diarias, compartidas entre los modelos gratuitos. No alcanza para sesiones muy largas de agente, pero sirve como reserva.

¿Cómo extender tus créditos sin pagar?

No encontré un método oficial para aumentar ilimitadamente los créditos de Big Pickle. La estrategia práctica es combinar cuotas independientes: OpenCode gratuito, Antigravity Free y Copilot Free.

También podés reducir el consumo usando conversaciones nuevas para tareas distintas y evitando mandar repositorios completos cuando solo necesitás modificar unos archivos.

Y algo importante: los modelos gratuitos locales con Ollama no tienen cuotas, pero en una máquina con 4 GB de RAM difícilmente consigas un agente comparable a Claude Code para tareas complejas.

Mi recomendación: conservá OpenCode como agente principal, probá GLM-5.3 Flash y DeepSeek V4.1 Flash, e instalá Antigravity CLI como segundo agente. Así tenés dos servicios distintos para seguir trabajando cuando uno alcance su límite, sin pagar suscripciones.


#!/usr/bin/env bash
# Borra las credenciales de la cuenta de Google de Antigravity CLI (agy)
# sin tocar el historial de conversaciones.
#
# Uso:
#   agy-borrar-cuenta              # pide confirmación
#   agy-borrar-cuenta --si         # sin preguntar (yes)
#   agy-borrar-cuenta --dry-run    # solo muestra qué haría
#
# Qué borra:  ~/.gemini/antigravity-cli/antigravity-oauth-token
# Qué conserva: conversations/, brain/, history.jsonl,
#               conversation_summaries.db, settings.json, proyectos, MCP...
#
# Después de ejecutarlo tendrás que volver a iniciar sesión al abrir `agy`.

set -uo pipefail

CONFIG_DIR="${AGY_CONFIG_DIR:-$HOME/.gemini/antigravity-cli}"

# Archivos que contienen credenciales/identidad de la cuenta de Google.
# (Si en el futuro Antigravity añade más, se agregan aquí.)
ARCHIVOS_CUENTA=(
  "$CONFIG_DIR/antigravity-oauth-token"
)

# Rutas que NUNCA se deben tocar (historial).
HISTORIAL=(
  "$CONFIG_DIR/conversations"
  "$CONFIG_DIR/brain"
  "$CONFIG_DIR/history.jsonl"
  "$CONFIG_DIR/conversation_summaries.db"
)

DRY_RUN=0
ASUMIR_SI=0

for arg in "$@"; do
  case "$arg" in
    --dry-run|-n) DRY_RUN=1 ;;
    --si|--yes|-y) ASUMIR_SI=1 ;;
    -h|--help)
      sed -n '2,14p' "$0" | sed 's/^# \{0,1\}//'
      exit 0
      ;;
    *)
      echo "Opción desconocida: $arg (usa --help)" >&2
      exit 2
      ;;
  esac
done

if [[ ! -d "$CONFIG_DIR" ]]; then
  echo "No existe $CONFIG_DIR — ¿está instalado Antigravity CLI?" >&2
  exit 1
fi

# Inventario previo del historial, para comprobar que no se toca.
historial_antes=$(
  find "${HISTORIAL[@]}" -type f 2>/dev/null | wc -l
)

existentes=()
for f in "${ARCHIVOS_CUENTA[@]}"; do
  [[ -e "$f" ]] && existentes+=("$f")
done

if [[ ${#existentes[@]} -eq 0 ]]; then
  echo "No hay archivos de cuenta que borrar en $CONFIG_DIR."
  echo "Parece que ya no hay sesión de Google guardada."
  exit 0
fi

echo "Se van a borrar (credenciales de la cuenta):"
printf '  - %s\n' "${existentes[@]}"
echo
echo "Se conserva (historial y ajustes):"
printf '  - %s\n' "${HISTORIAL[@]}"
echo

if [[ $DRY_RUN -eq 1 ]]; then
  echo "[dry-run] No se borró nada."
  exit 0
fi

if [[ $ASUMIR_SI -eq 0 ]]; then
  read -r -p "¿Borrar la cuenta guardada? [s/N] " resp
  case "$resp" in
    s|S|si|Si|SI|y|Y|yes) ;;
    *) echo "Cancelado."; exit 0 ;;
  esac
fi

borrado_ok=1
for f in "${existentes[@]}"; do
  if command -v shred >/dev/null 2>&1; then
    shred -u -- "$f" || { echo "ERROR: no se pudo borrar $f" >&2; borrado_ok=0; }
  else
    rm -f -- "$f" || { echo "ERROR: no se pudo borrar $f" >&2; borrado_ok=0; }
  fi
  [[ -e "$f" ]] && { echo "ERROR: $f sigue existiendo" >&2; borrado_ok=0; }
done

historial_despues=$(
  find "${HISTORIAL[@]}" -type f 2>/dev/null | wc -l
)

echo
if [[ $borrado_ok -eq 1 ]]; then
  echo "Credenciales de la cuenta borradas."
else
  echo "Hubo errores al borrar (ver arriba)." >&2
fi

if [[ "$historial_antes" -eq "$historial_despues" ]]; then
  echo "Historial intacto: $historial_despues archivos."
else
  echo "AVISO: el número de archivos de historial cambió ($historial_antes → $historial_despues)." >&2
fi

echo "La próxima vez que abras 'agy' tendrás que iniciar sesión de nuevo."

# Aviso: el email de la cuenta puede aparecer dentro del historial
# (transcripciones). Eso NO se toca aquí porque pediste conservarlo.
exit $(( borrado_ok == 1 ? 0 : 1 ))

5. ChatGPT / Codex con OAuth: sin API key y sin pagar

OpenAI también se puede usar sin API key: la cuenta de ChatGPT permite autenticarse por OAuth y el proyecto openai-oauth expone una API compatible con OpenAI. OpenCode se conecta como si fuera un proveedor normal, con tool calls nativos.

Requisitos

  • Una cuenta de ChatGPT (el plan free alcanza, pero el cupo es chico).
  • Node.js y npm.
  • Un navegador para autorizar una sola vez.

Instalación

mkdir -p ~/openai-oauth
cd ~/openai-oauth
npm init -y
npm install openai-oauth@2.0.0
npx openai-oauth@2.0.0 login

Si la máquina es headless (sin entorno gráfico), usá:

npx openai-oauth@2.0.0 login --no-open

Te va a imprimir una URL de auth.openai.com. Abrila en cualquier navegador donde ya tengas la sesión de ChatGPT, elegí la cuenta, aceptá el consentimiento de Codex y listo. El callback vuelve a http://localhost:1455/auth/callback y las credenciales quedan en:

~/.codex/auth.json   # permisos 600

Levantar el proxy

npx openai-oauth@2.0.0 --host 127.0.0.1 --port 10531

Eso expone:

http://127.0.0.1:10531/v1

con endpoints compatibles con OpenAI (/v1/models, /v1/chat/completions, /v1/responses).

Servicio systemd (opcional)

Para que arranque solo:

# ~/.config/systemd/user/openai-oauth.service
[Unit]
Description=OpenAI OAuth proxy
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
WorkingDirectory=%h/openai-oauth
ExecStart=/usr/bin/node %h/openai-oauth/node_modules/openai-oauth/dist/cli.js --host 127.0.0.1 --port 10531
Restart=always
RestartSec=3

[Install]
WantedBy=default.target

systemctl --user daemon-reload
systemctl --user enable --now openai-oauth.service
systemctl --user status openai-oauth.service

Configurar OpenCode

En ~/.config/opencode/opencode.json:

{
  "providers": {
    "chatgpt-oauth": {
      "name": "ChatGPT (OAuth)",
      "package": "@opencode/ai/providers/openai-compatible",
      "settings": {
        "baseURL": "http://127.0.0.1:10531/v1",
        "apiKey": "dummy"
      },
      "models": {
        "gpt-6-luna": {
          "name": "GPT-6 Luna",
          "capabilities": { "tools": true, "input": ["text", "image"], "output": ["text"] },
          "limit": { "context": 500000, "output": 32768 }
        },
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra",
          "capabilities": { "tools": true, "input": ["text", "image"], "output": ["text"] },
          "limit": { "context": 272000, "output": 32768 }
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna",
          "capabilities": { "tools": true, "input": ["text", "image"], "output": ["text"] },
          "limit": { "context": 272000, "output": 32768 }
        }
      }
    }
  }
}

El apiKey: "dummy" es solo para que el cliente OpenAI-compatible no se queje; el proxy lo ignora.

Después abrís OpenCode, /models → ChatGPT (OAuth) → GPT-6 Luna.

Si el proxy corre en otra máquina

Dejalo escuchando en 127.0.0.1 y llevá el puerto por SSH:

ssh -N -L 127.0.0.1:10531:127.0.0.1:10531 usuario@otra-maquina

Así no lo exponés a la LAN.

Aviso importante: el plan free tiene poco cupo

El plan free de ChatGPT incluye acceso a Codex, pero con un cupo muy chico. No es para uso intensivo: dos o tres pedidos con tool calls pueden agotarlo. No te cobran nada, simplemente se corta hasta que resetee. El cupo se comparte con Codex CLI/IDE.

Para no gastarlo en tareas de mantenimiento, podés hacer que los agentes internos de OpenCode usen un modelo gratis:

"agents": {
  "title": { "model": "opencode/big-pickle" },
  "summary": { "model": "opencode/big-pickle" },
  "compaction": { "model": "opencode/big-pickle" }
}

Así los títulos, resúmenes y la compactación no consumen el cupo de ChatGPT.

GitHub Copilot en OpenCode

Copilot usa OAuth de dispositivo, no API key:

opencode auth login

Elegí GitHub Copilot → GitHub.com y seguí el flujo: te da un código, abrís https://github.com/login/device, lo pegás y autorizás. OpenCode detecta el plan y trae la lista de modelos de tu cuenta.

La cuenta necesita acceso a Copilot Chat. Si no tenés suscripción, el plan Copilot Free alcanza, con créditos mensuales limitados.

Antigravity no tiene, hasta donde probé, una API compatible con OpenAI, así que no se puede enchufar a OpenCode como proveedor. La estrategia es usarlo como segundo agente cuando OpenCode se queda sin cuota.

Estrategia para no pagar

  1. Día a día: los modelos gratis de OpenCode (big-pickle, flint-40b-free, GLM-5.3 Flash, DeepSeek V4.1 Flash).
  2. Segundo agente: Antigravity (agy) con Gemini 3.8 Flash o Claude Sonnet 4.6.
  3. Tercer agente: GitHub Copilot Free.
  4. ChatGPT/Codex: solo para lo difícil, porque el cupo free es chico.
  5. Ahorro extra: usá conversaciones nuevas para tareas distintas, no mandes repos completos y configurá agents.title/summary/compaction con un modelo gratis.

Ninguno de estos métodos es oficial ni está garantizado: OpenAI, Google y GitHub pueden cambiar los límites, los modelos o el acceso cuando quieran. La ventaja es que no hay tarjeta ni factura: si se termina la cuota, esperás o cambiás de agente.
