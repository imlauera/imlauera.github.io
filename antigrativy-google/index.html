Google Antigravity CLI: mi alternativa favorita

Plan gratuito

Agente autónomo de terminal

Google reemplazó el acceso gratuito individual de Gemini CLI por Antigravity CLI el 18 de junio de 2026. Es importante porque muchos tutoriales todavía recomiendan el viejo Gemini CLI.

image

GitHub+1

Antigravity permite ejecutar tareas de programación y utilizar herramientas desde la terminal, con un plan de $0 y cuotas limitadas.

En Arch Linux:

curl -fsSL https://antigravity.google/cli/install.sh -o /tmp/agy-install.sh
less /tmp/agy-install.sh
bash /tmp/agy-install.sh

Luego:

~/.local/bin/agy

Te pedirá iniciar sesión con Google. Es una alternativa genuina a Claude Code, aunque necesita autenticación y está sujeta a límites gratuitos.

3. GitHub Copilot CLI: otro agente gratuito

GitHub ofrece Copilot CLI en su plan Free. Puede modificar archivos, ejecutar herramientas y trabajar autónomamente sobre proyectos.

Instalación:

npm install -g @github/copilot
copilot

Dentro de Copilot escribí /login para autenticarte.

Tiene créditos gratuitos mensuales y funciona directamente en Linux. Su inconveniente es que la cuota también se termina.

image

GitHub Docs+1

4. OpenRouter: más modelos sin pagar

OpenRouter tiene modelos gratuitos que podés conectar a OpenCode utilizando una API key.

Su límite gratuito normal es de 50 solicitudes diarias, compartidas entre los modelos gratuitos. No alcanza para sesiones muy largas de agente, pero sirve como reserva.

¿Cómo extender tus créditos sin pagar?

No encontré un método oficial para aumentar ilimitadamente los créditos de Big Pickle. La estrategia práctica es combinar cuotas independientes: OpenCode gratuito, Antigravity Free y Copilot Free.

También podés reducir el consumo usando conversaciones nuevas para tareas distintas y evitando mandar repositorios completos cuando solo necesitás modificar unos archivos.

Y algo importante: los modelos gratuitos locales con Ollama no tienen cuotas, pero en una máquina con 4 GB de RAM difícilmente consigas un agente comparable a Claude Code para tareas complejas.

Mi recomendación: conservá OpenCode como agente principal, probá GLM-5.3 Flash y DeepSeek V4.1 Flash, e instalá Antigravity CLI como segundo agente. Así tenés dos servicios distintos para seguir trabajando cuando uno alcance su límite, sin pagar suscripciones.
