Tutorial: descargar video a máxima calidad, cortarlo y crear thumbnail con rostro de fondo

Flujo completo que usé para generar hotz_ai_safety_thumbnail.png:

  1. Descargar un video de YouTube a máxima calidad con yt-dlp.
  2. Cortar un segmento (02:39 → 32:00) con ffmpeg sin re-encode.
  3. Buscar fotos de la persona (George Hotz) en Binternet (pinterest.lurkmore.com), un front-end respetuoso de Pinterest que está protegido por Anubis (proof-of-work anti-bot).
  4. Generar el thumbnail con un script Python basado en bill_gates_meme.py.

1. Descargar el video a máxima calidad

# Video + audio por separado a la mejor calidad posible, luego merge a un solo mp4
yt-dlp \
  -f "bestvideo[ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]/best" \
  --merge-output-format mp4 \
  -o "VIDEO_ID.%(ext)s" \
  VIDEO_ID
  • bestvideo[ext=mp4]+bestaudio[ext=m4a]: descarga pista de video y audio separadas y las une al final.
  • La última parte (best[ext=mp4]/best) es el fallback si no hay split.
  • Si la descarga se corta (timeout), se reanuda al correr el mismo comando (queda un .part).

Para correrlo en segundo plano:

nohup yt-dlp ... > download.log 2>&1 &

2. Cortar el segmento con ffmpeg

ffmpeg -y \
  -ss 00:02:39 -to 00:32:00 \
  -i VIDEO.mp4 \
  -c copy \
  -avoid_negative_ts make_zero \
  VIDEO_cortado.mp4
  • -ss ... -to ...: intervalo de inicio y fin (mm:ss).
  • -c copy: copie streams sin re-encode → es instantáneo y no pierde calidad. El único costo: el corte de inicio cae en el keyframe más cercano (unos segundos de imprecisión). Si necesitás exactitud de frame, sacá -c copy (re-encode lento).

3. Buscar fotos en pinterest.lurkmore.com (Binternet)

El sitio está protegido por Anubis v1.27 (/tmp/opencode/main.mjs): usa un proof-of-work de dificultad 2 + fingerprinting, no sirve curl ni chromium --headless=new --dump-dom (da “Access denied”).

$ curl https://pinterest.lurkmore.com/            → "Making sure you're not a bot!"
$ chromium --headless=new --dump-dom ...          → "Oh noes! Access denied"

Solución: opencli Browser Bridge

opencli es un CLI que controla un Chrome real (con extensión), que sí ejecuta el JS del challenge.

opencli doctor                          # verificar que el daemon + perfil están conectados
opencli profile list                    # ver perfiles (ej: ng3r53je)

# Abrir una URL en el navegador controlado
opencli browser ng3r53je open "https://pinterest.lurkmore.com/"

# Interrogar la página
opencli browser ng3r53je get title      # "Binternet"
opencli browser ng3r53je get url
opencli browser ng3r53je get html --max 6000

Ojo: el endpoint de búsqueda no es /search/pins/?q=, ese da 404. El path real de Binternet es:

opencli browser ng3r53je open "https://pinterest.lurkmore.com/search.php?q=george+hotz"

Las páginas de resultados traen bloques como:

<a class="img-result" href="/image_proxy.php?url=https://i.pinimg.com/originals/HASH.jpg">
  <img loading="lazy" src="/image_proxy.php?url=https://i.pinimg.com/originals/HASH.jpg">
</a>

Descargar las imágenes

Las URLs reales apuntan a i.pinimg.com (CDN de Pinterest), así que se bajan directo sin pasar por Anubis:

import re, urllib.request, subprocess
html = subprocess.run(
    ['opencli', 'browser', 'ng3r53je', 'get', 'html', '--max', '0'],
    capture_output=True, text=True).stdout
urls = re.findall(r'image_proxy\.php\?url=([^"\']+)', html)
for i, u in enumerate(dict.fromkeys(urls)):
    urllib.request.urlretrieve(u.replace('&amp;', '&'),
                               f"hotz_{i}.{u.split('.')[-1]}")

La paginación va por ?bookmark=...&csrftoken=... (enlace “Next page” al final del HTML).

4. Generar el thumbnail (estilo bill_gates_meme.py)

Adapté bill_gates_meme.py → hotz_ai_safety_meme.py. Diferencias clave:

bill_gates_meme.py hotz_ai_safety_meme.py
Fondo bill_gates_serio.jpg (vertical) foto de George Hotz 4f3bd24...jpg (1920x1080)
Crop solo vertical (asume foto alta) cover-fit: recorta ancho o alto según el aspect ratio de destino
Tamaño 1080x1350 (vertical) 1200x720 (YouTube landscape)
Texto BILL GATES MIENTE SOBRE LA IA. + body largo STOP AI SAFETY + 4 líneas de body

El crop robusto para cualquier orientación de foto de fondo:

img = cv2.imread(SRC)
ih, iw = img.shape[:2]
target_ar = W / H                       # 1200/720 = 1.667
if iw / ih > target_ar:                 # foto muy ancha → recortar los costados
    nw = int(ih * target_ar);  x0 = (iw - nw) // 2
    tim = img[:, x0:x0 + nw]
else:                                   # foto muy alta → recortar arriba/abajo
    nh = int(iw / target_ar);  y0 = (ih - nh) // 2
    tim = img[y0:y0 + nh, :]

Escaleta del estilo (bill_gates_meme.py base):

  • Oscurecer el fondo (arr *= 0.78).
  • Fuente Impact (/home/esotericwarfare/fonts/impact.ttf), auto-ajuste del tamaño para que el texto más ancho entre en W - 2*PAD_X.
  • Panel central redondeado semitransparente con blur.
  • Texto con sombra desenfocada + stroke oscuro.
  • Header amarillo #ffb020; body con gradiente naranja → rojo; última línea amarilla para destacar.

Resultado

  • hotz_ai_safety_meme.py: script generador.
  • hotz_ai_safety_thumbnail.png: 1200x720 RGB, ~1.8 MB. Todo el texto junto y centrado.
python3 hotz_ai_safety_meme.py
# saved hotz_ai_safety_thumbnail.png | head 99 body 66 | panel 95 - 625

Notas / trucos

  • Si no tenés un modelo de detección facial (OpenCV 5 no trae Haar), pedile al usuario que elija el frame porque la IA no puede ver imágenes en esta sesión.
  • Anubis cambia el challenge en cada request (issuedAt + randomData + cookie del PoW), así que el “token” de curl no es reutilizable: por eso conviene el browser real (opencli) de una.
  • ffmpeg -ss antes de -i busca con keyframe-accurate seek; -ss después de -i hace frame-accurate pero decodifica todo.
