Leer en voz alta (navegador)

Listo para leer.

Usa la voz del navegador (Web Speech API). Para descargar MP3, usá el reproductor/descarga cuando esté disponible.

ytfzf -L --type=channel asdf # Busca canal
ytfzf --rii # Actualiza instanacias
ytfzf -t -T ueberzug asdf
ytfzf -L asdf 
yt-dlp -f134+140 <link obtenido>
