Piracy

En realidad las listas anti-pirateria sirven para buscar pirateria. Despues le pedis a oopencode

Descargame todas las listas en un solo archivo y despues busca en ese archivo todos los dominios en donde puede ser que tenga el directo de la formula1 busca en yandex.ru para bloquearlo con curl fijate cual funciona y cual no (para bloquear pirateria).

1. Block List Project (el más fresco, recomendado)

Descargar solo los archivos que te interesan (piracy + torrent):

wget https://blocklistproject.github.io/Lists/piracy.txt
wget https://blocklistproject.github.io/Lists/torrent.txt

Clonar el repo completo (todas las categorías: ads, malware, porn, gambling, etc.):

git clone https://github.com/blocklistproject/Lists.git

Combinar piracy + torrent en un solo hosts:

cat piracy.txt torrent.txt | sort -u > piracy-full-hosts.txt

2. HaGeZi (activo, pero usá el formato wildcard, no el hosts viejo)

Descargar la lista wildcard anti-piratería directamente:

wget https://raw.githubusercontent.com/hagezi/dns-blocklists/main/wildcard/anti.piracy-onlydomains.txt

Clonar el repo completo:

git clone https://github.com/hagezi/dns-blocklists.git

(las listas están en la carpeta wildcard/ — el formato hosts/ y domains/ quedaron discontinuados desde el 1 de agosto de 2026)

3. NextDNS piracy-blocklists (con la reserva que te comenté — menos actualizada)

git clone https://github.com/nextdns/piracy-blocklists.git

Adentro vas a encontrar archivos separados como warez, torrent-websites, streaming-video. Podés concatenarlos igual que arriba.

Nota práctica: el archivo de HaGeZi en formato wildcard usa sintaxis ||dominio.com^ o *.dominio.com, no el clásico 0.0.0.0 dominio.com de /etc/hosts. Si lo querés meter directo en tu /etc/hosts, tenés que convertirlo primero (o usar directamente Block List Project, que sí viene en formato hosts nativo).

  • Redes Torrent/P2P: https://blocklistproject.github.io/Lists/torrent.txt

2. HaGeZi DNS Blocklists (La más completa y actualizada)

  • Formato Dominios (Fácil de convertir a hosts): https://raw.githubusercontent.com/hagezi/dns-blocklists/main/domains/anti.piracy.txt

Este proyecto recopila y genera listas estáticas diarias en múltiples formatos, incluyendo una carpeta específica para piratería en formato 0.0.0.0 listo para usar [[50]].

⚙️ Script de automatización (Copiar y Pegar)

Este script de Bash descarga las listas, las convierte al formato correcto de /etc/hosts, elimina duplicados, hace una copia de seguridad de tu archivo actual y aplica el bloqueo.

Ejecútalo con permisos de administrador (sudo):

#!/bin/bash
echo "🛡️  Iniciando configuración de bloqueo de piratería..."

# 1. Crear directorio temporal de trabajo
WORK_DIR=$(mktemp -d)
cd "$WORK_DIR" || exit

# 2. Descargar las listas verificadas
echo "⬇️  Descargando listas..."
wget -q -O blp_piracy.txt "https://blocklistproject.github.io/Lists/piracy.txt"
wget -q -O blp_torrent.txt "https://blocklistproject.github.io/Lists/torrent.txt"
wget -q -O sefinek_piracy.txt "https://blocklist.sefinek.net/generated/v1/0.0.0.0/piracy/sefinek.hosts.txt"
# Descargamos la de dominios de HaGeZi y le añadimos el prefijo 0.0.0.0 para que sea compatible con hosts
wget -q -O hagezi_domains.txt "https://raw.githubusercontent.com/hagezi/dns-blocklists/main/domains/anti.piracy.txt"
sed -i 's/^/0.0.0.0 /' hagezi_domains.txt

# 3. Combinar, limpiar comentarios, líneas vacías y eliminar duplicados
echo "🔄  Procesando y combinando listas..."
cat blp_piracy.txt blp_torrent.txt sefinek_piracy.txt hagezi_domains.txt | \
  grep -v '^#' | \
  grep -v '^$' | \
  grep '0\.0\.0\.0' | \
  sort -u > combined_piracy_hosts.txt

TOTAL_DOMAINS=$(wc -l < combined_piracy_hosts.txt)
echo "✅  Se han procesado $TOTAL_DOMAINS dominios únicos de piratería."

# 4. Copia de seguridad del /etc/hosts actual
echo "💾  Creando copia de seguridad de /etc/hosts..."
sudo cp /etc/hosts "/etc/hosts.backup.$(date +%Y%m%d_%H%M%S)"

# 5. Aplicar la lista al final del archivo /etc/hosts
echo "🔒  Aplicando bloqueo a /etc/hosts..."
echo "" | sudo tee -a /etc/hosts > /dev/null
echo "# === BLOQUEO DE PIRATERÍA (Generado el $(date)) ===" | sudo tee -a /etc/hosts > /dev/null
cat combined_piracy_hosts.txt | sudo tee -a /etc/hosts > /dev/null

# 6. Limpiar caché DNS del sistema (varía según SO, este es para Linux systemd)
if command -v systemd-resolve &> /dev/null; then
    sudo systemd-resolve --flush-caches
elif command -v resolvectl &> /dev/null; then
    sudo resolvectl flush-caches
fi

echo "🎉  ¡Proceso completado! La piratería está siendo bloqueada a nivel de DNS local."
echo "⚠️  IMPORTANTE: Si algún sitio legítimo deja de funcionar, revisa /etc/hosts y elimina la línea correspondiente."

# Limpieza
cd - > /dev/null
rm -rf "$WORK_DIR"

⚠️ Advertencias y Consideraciones Técnicas (Leer antes de aplicar)

  1. Falsos Positivos: Las listas de piratería son inherentemente agresivas. Es posible que bloqueen servicios de almacenamiento en la nube legítimos (como ciertos dominios de mega.nz, mediafire o proxies de privacidad) porque comparten infraestructura con sitios de warez. Prueba esto primero en un solo dispositivo antes de desplegarlo en tu router o Pi-hole de toda la red.
  2. Formato Wildcard vs Hosts: Si usas AdGuard Home, Pi-hole v6, o Blocky, no uses el script de arriba. En su lugar, importa directamente la URL wildcard o domains de HaGeZi en la interfaz de tu servidor DNS. Es más eficiente que saturar el archivo /etc/hosts.
  3. Evasión fácil: Este bloqueo es a nivel de DNS. Un usuario con conocimientos técnicos puede evadirlo simplemente cambiando los DNS de su dispositivo a 1.1.1.1 o 8.8.8.8, o editando su propio archivo hosts local. Para un bloqueo real en una red, debes interceptar y bloquear las peticiones DNS salientes (DNS Sinkholing) en el router.
  4. No bloquea IPs directas: Si un sitio de piratería se accede directamente por su dirección IP (ej. http://192.168.x.x), el bloqueo por nombre de dominio en /etc/hosts no tendrá efecto.

Si deseas una lista aún más masiva (pero con mayor riesgo de romper servicios legítimos), puedes explorar el repositorio de fabriziosalmi/blacklists, que agrega decenas de fuentes diarias en un solo archivo [[70]], aunque se recomienda empezar con la combinación de Block List Project + HaGeZi que te proporciono arriba por su mejor equilibrio entre eficacia y estabilidad.
