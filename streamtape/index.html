Tutorial: cómo descargar videos de Streamtape

Método manual para obtener la URL directa del video sin usar yt-dlp (streaamtape ya no tiene extractor oficial soportado).

Requisitos

  • curl (instalado por defecto en casi cualquier Linux)
  • ffprobe/ffmpeg (opcional, solo para verificar)
which curl ffprobe 2>&1

Pasos

1. Agarrá la URL del embed

Cada botón del sitio apunta a un link con formato:

https://streamtape.com/e/XXXXXXXXXXXXXX

Esa URL de tipo /e/ es la página del reproductor (embed).

2. Bajá la página del embed

curl -s -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0 Safari/537.36" \
     "https://streamtape.com/e/XXXXXXXXXXXXXX" -o embed.html

El -A (User-Agent) es necesario porque si el sitio detecta un cliente sin navegador puede devolver un error.

3. Buscá el get_video en el HTML

La página tiene varios links con el token del video. Se arman con JavaScript ofuscado, pero al final todos terminan igual:

<div id="ideoolink"  style="display:none;">//streamtape.com/get_video?id=XXXXXXXXXXXXXX&expires=1234567890&ip=AAAA&token=BBBB</div>
<span id="botlink"    style="display:none;">//streamtape.com/get_video?id=XXXXXXXXXXXXXX&expires=1234567890&ip=AAAA&token=BBBB</span>
<div id="robotlink"   style="display:none;">//streamtape.com/get_video?id=XXXXXXXXXXXXXX&expires=1234567890&ip=AAAA&token=BBBB</div>

Cualquiera de los tres sirve. Fijate que:

curl -s -A "Mozilla/5.0" "https://streamtape.com/e/XXXXXXXXXXXXXX" | grep -o 'get_video?id=[^"]*' | sort -u

4. Hackeá el link real

Streamtape arma la URL real con substring() para que no se vea el token en el HTML plano. Por ejemplo:

document.getElementById('botlink').innerHTML = '//streamtape.com/' + ('xyzaget_video?id=...&token=STf_K4qLLT4s').substring(4);
  • .substring(4) elimina los 4 primeros caracteres (xyza), quedando el get_video?id=... final.
  • Además, como la página obfuscada agrega basura al principio (por ej. xyzaget_...), el resultado real siempre es get_video?id=....

Resultado:

https://streamtape.com/get_video?id=XXXXXXXXXXXXXX&expires=1234567890&ip=AAAA&token=BBBB

Si no querés leer el JS a mano, también podés usar las herramientas de desarrollo del navegador (F12 → pestaña “Network”) y mirar la petición que hace el video cuando arranca.

5. Seguí la redirección y descargá

La URL get_video devuelve un HTTP 302 hacia el CDN real, con los headers content-type: video/mp4. Para descargar:

curl -sL -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0 Safari/537.36" \
     -e "https://streamtape.com/" \
     -o "video.mp4" \
     "https://streamtape.com/get_video?id=XXXXXXXXXXXXXX&expires=1234567890&ip=AAAA&token=BBBB&stream=1"
  • -L: seguir la redirección 302 (importante).
  • -e: setear el Referer (a veces el CDN lo exige).
  • &stream=1: es lo que el reproductor real agrega al final; probá con y sin él si una variante falla.

6. Verificá el archivo

ls -la video.mp4
ffprobe -v error -show_entries format=duration,size -of default=noprint_wrappers=1 video.mp4

Resumen / checklist

Paso Comando clave
1. Embed URL https://streamtape.com/e/XXXX
2. Bajar página curl -A "<UA>" ... -o embed.html
3. Encontrar token grep -o 'get_video?id=[^"]*'
4. Armar link https://streamtape.com/get_video?<params>
5. Descargar curl -sL -e referer -o video.mp4 <url>
6. Verificar ffprobe video.mp4

Notas

  • Los expires y el token caducan (generalmente en un par de días). Si se rompe el enlace, repetí los pasos 2-4 para sacar uno nuevo.
  • El ip está asociado a la IP desde la que pediste la página del embed; si la descarga la hacés desde otra IP, puede fallar.
  • Para sitios similares (voe.sx, hgcloud, streamruby, etc.) el mismo enfoque sirve: bajá la página embed, buscá el get_video / videolink / fuente directa en el HTML o JS, armá la URL y descargá con curl -L.
