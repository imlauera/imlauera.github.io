Optimización de batería — Moto G (4) Athène

Dispositivo: Moto G (4) | Android: 7 (SDK 24) | Root: Magisk 30.7 Fecha: 2026-09-15

1. Diagnóstico

Estado de la batería

Parámetro Valor
Capacidad de diseño 3059 mAh
Capacidad real 1552 mAh
Salud ~50% (POWER_SUPPLY_AGE=50)
Carga actual 96–97%
Temperatura 29 °C

Causa del apagón con la cámara

La batería está desgastada al 50%. El flash demanda ~1.4 A (POWER_SUPPLY_FLASH_CURRENT_MAX); al abrir la cámara, la tensión de la batería degradada colapsa bajo el umbral de corte y el teléfono se apaga (protección por baja tensión).

2.4 Aclaración sobre la app de Google (IMPORTANTE)

La app com.google.android.googlequicksearchbox contiene el launcher de inicio (com.google.android.launcher / .GEL). Desactivarla dejaría la HOME en blanco (solo “FallbackHome” de Ajustes).

  • Decisión final: se deja HABILITADA para que la HOME funcione.
  • Se le aplicaron restricciones de background (RUN_IN_BACKGROUND y WAKE_LOCK ignore) para que igual no drene batería en segundo plano.
  • Verificado tras reiniciar: HOME OK. No volver a desactivarla.

2.5 Límite de CPU aplicado (reduce picos de corriente)

  • Clúster 0–3 (antes hasta 1516 MHz): máx 1344 MHz, mín 806 MHz
  • Clúster 4–7: sin cambios (ya estaba en su máximo hardware 1209 MHz)

2.8 Script de arranque persistente (Magisk service.d)

Instalado en /data/adb/service.d/battery_opt.sh (se ejecuta en cada boot):

#!/system/bin/sh
for c in 0 1 2 3; do
  base=/sys/devices/system/cpu/cpu$c/cpufreq
  if [ -f "$base/scaling_max_freq" ]; then
    echo 1344000 > "$base/scaling_max_freq"
  fi
  if [ -f "$base/scaling_min_freq" ]; then
    echo 806400 > "$base/scaling_min_freq"
  fi
done
settings put global wifi_scan_always_enabled 0
settings put global window_animation_scale 0
settings put global transition_animation_scale 0
settings put global animator_duration_scale 0
settings put system screen_off_timeout 30000
exit 0

3. Resultado

  • Solo el proveedor de calendario del sistema queda en segundo plano (mínimo). Las apps pesadas (Play Store, Telegram, WhatsApp, Messages, Calendar) se detienen.
  • La app de Google queda habilitada (necesaria para la HOME) pero con background restringido.
  • El límite de CPU y los ajustes ahora persisten tras reiniciar (verificado: CPU = 1344 MHz, animaciones = 0 al arrancar).

4. Recomendaciones para el apagón con la cámara

  1. No usar el flash (dispara el pico de ~1.4 A).
  2. Usar la cámara con batería arriba de ~40%.
  3. El arreglo definitivo: cambiar la batería (modelo BL-0427, ~US$10). Es la única solución real al desgaste del 50%.

5. Comandos útiles para revertir

Volver a habilitar la app de Google

NOTA: Esta app contiene el launcher de la HOME. Solo reactivala si alguien la desactivó (no es el estado actual recomendado).

adb shell pm enable com.google.android.googlequicksearchbox

Volver a habilitar la app Shutdown

adb shell pm enable com.samiadom.Shutdown
adb shell settings put secure enabled_accessibility_services com.samiadom.Shutdown/.accessService
adb shell settings put secure accessibility_enabled 1

Restaurar CPU original

adb shell "su -c 'echo 1516800 > /sys/devices/system/cpu/cpu0/cpufreq/scaling_max_freq'"

(borrar /data/adb/service.d/battery_opt.sh para que no se repita en cada boot)

Restaurar el bloatware de Moto

adb shell pm enable com.motorola.timeweatherwidget
adb shell pm enable com.motorola.actions
adb shell pm enable com.motorola.motocare
