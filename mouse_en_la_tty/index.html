Leer en voz alta (navegador)

Listo para leer.

Usa la voz del navegador (Web Speech API). Para descargar MP3, usá el reproductor/descarga cuando esté disponible.

sudo pacman -S gpm

Editá el archivo /etc/conf.d/gpm:

GPM_ARGS="-m
/dev/input/mice -t imps2"

sudo systemctl enable gpm
sudo systemctl start gpm

Podés copiar y pegar seleccionando el texto y pegandolo con click derecho.
