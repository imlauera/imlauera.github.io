Tutorial: Bloquear TODA la publicidad con AdAway (Android rooteado)

Sin PC, sin VPN, sin gastar batería. Funciona en apps y en el navegador.

Requisitos

  • Celular rooteado (Magisk)
  • AdAway instalado desde F-Droid (no usar Play Store)

Pasos

1. Abrir AdAway y dar permiso root

Al abrir pide acceso superusuario → Conceder.

2. Agregar las listas de hosts

Menú lateral (☰) → Hosts sources → botón + → pegar cada URL:

https://adaway.org/hosts.txt

https://pgl.yoyo.org/adservers/serverlist.php?hostformat=hosts&showintro=0&mimetype=plaintext

https://raw.githubusercontent.com/StevenBlack/hosts/master/hosts

https://raw.githubusercontent.com/anudeepND/blacklist/master/adservers.txt

https://raw.githubusercontent.com/jerryn70/GoodbyeAds/master/Hosts/GoodbyeAds.txt

https://raw.githubusercontent.com/r-a-y/mobile-hosts/master/AdguardDNS.txt

https://someonewhocares.org/hosts/zero/hosts

https://raw.githubusercontent.com/r-a-y/mobile-hosts/master/AdguardMobileSpyware.txt

⚠️ Pegar la URL completa y verificar que no quede doble https://https://.

3. NO agregar más listas gigantes ⚠️

En un celular de 2GB RAM ese set ya suma ~600 mil dominios y es el límite. Si agrega listas enormes (ej. 1Hosts Xtra, hBlock), AdAway se queda clavado en “Building hosts file” para siempre y hay que forzar cerrarlo y quitarlas.

4. Aplicar

Volver a Home → scrollear hacia abajo → tocar UPDATE HOSTS. Descarga unos 25MB (paciencia, tarda varios minutos). Cuando termina pregunta si quiere reiniciar → aceptar.

Listo

Después del reinicio AdAway dice “AdAway is active” y bloquea toda la publicidad. Si alguna página o app se rompe, menú lateral → whitelist y agregar el dominio afectado.

Si algo sale mal

Se cuelga en “Building hosts file”: forzar cierre de AdAway desde Ajustes → Apps → abrir de nuevo → desmarcar las listas más grandes → UPDATE HOSTS otra vez.
