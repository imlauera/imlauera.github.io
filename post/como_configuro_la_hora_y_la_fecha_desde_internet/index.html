Usa la voz del navegador (Web Speech API). Para descargar MP3, usá el reproductor/descarga cuando esté disponible.

sudo pacman -S ntp
timedatectl set-ntp true
sudo vim /etc/ntp.conf
server pool.ntp.org
sudo ntpdate pool.ntp.org
sudo systemctl enable ntpd
sudo systemctl start ntpd
