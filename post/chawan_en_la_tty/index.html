Chawan es un navegador de texto interactivo para la terminal. Se puede usar desde una TTY, como w3m o lynx, sin abrir un entorno gráfico. También incluye CSS y un motor JavaScript basado en QuickJS.

Instalar y abrir páginas

En Arch Linux, instalalo desde los repositorios oficiales:

sudo pacman -S chawan

Abrí una página con cha y su dirección:

cha https://example.com/

Activar JavaScript para un sitio

JavaScript está desactivado por defecto. Para habilitarlo solo en The Atlantic, agregá estas reglas a la configuración de Chawan, por ejemplo en ~/.chawan/config.toml:

[siteconf.theatlantic]
url = '^https?://www\.theatlantic\.com/'
scripting = true

[siteconf.nitter]
url = '^https?://nitter\.net/'
scripting = true

La configuración por sitio evita ejecutar scripts innecesariamente en todos los sitios. Chawan también puede usar ~/.config/chawan/config.toml; editá el archivo de configuración que ya estés usando y conservá el resto de sus opciones.

Desactivar CSS

Para desactivar las hojas de estilo en todos los sitios, agregá styling = false a la sección [buffer]:

[buffer]
styling = false

Si ya existe una sección [buffer], agregá solo la opción dentro de esa sección; no la declares una segunda vez.

Activar imágenes

Para permitir que Chawan cargue imágenes, usá images = true en [buffer]:

[buffer]
images = true

La terminal también debe soportar el protocolo de imágenes Sixel o Kitty. Chawan intenta detectarlo automáticamente; si no lo detecta, podés configurar image-mode como "sixel" o "kitty" en [display], siempre que tu terminal admita ese protocolo.

Límites

El motor JavaScript de Chawan no implementa todas las funciones de un navegador gráfico moderno, así que algunos sitios pueden no funcionar. Activar JavaScript no elimina bloqueos de acceso ni requisitos de inicio de sesión del sitio. Para más detalles, consultá la documentación de Chawan.
