YouTube Morphe: Parchear YouTube desde la consola

August 20, 2026
Youtube Morphe Patch Revanced

Esto lo hizo OpenCode a partir de la guía original se llama:

https://imlauera.github.io/post/revanced_parchear_youtube_desde_la_consola

ReVanced esta medio muerto (DMCA, forks, drama). Morphe es la continuationespiritual de ReVanced Extended, creada por inotia00 y los mismos devs. Soporta YouTube 21.x mientras ReVanced oficial se quedo en 20.40.45.

Que necesitas

  • Java 21+ (yo uso Java 26, cualquier version 21 o mayor sirve)
  • Morphe Desktop CLI (el parchador)
  • Morphe Patches (los parches en formato .mpp)
  • YouTube APK vanilla (el APK original de YouTube, sin parchear)
  • MicroG-RE (para loguearte con tu cuenta Google sin root)

1. Bajar las herramientas

Morphe Desktop CLI

# Ir a la pagina de releases y descargar el JAR
# https://github.com/MorpheApp/morphe-desktop/releases/latest
curl -L -o morphe-desktop-all.jar \
  https://github.com/MorpheApp/morphe-desktop/releases/download/v1.13.1/morphe-desktop-1.13.1-all.jar

Morphe Patches

# https://github.com/MorpheApp/morphe-patches/releases/latest
curl -L -o patches.mpp \
  https://github.com/MorpheApp/morphe-patches/releases/download/v1.39.1/patches-1.39.1.mpp

YouTube APK

Las versiones soportadas por Morphe patches (verificar en los releases cualesson las estables):

Version Estado
21.32.2 Experimental
21.31.523 Experimental
21.28.204 Experimental
21.04.223 Stable
20.51.39 Stable
20.31.42 Stable
20.21.37 Stable

Podes bajar el APK de APKMirror o APKPure. Si usas apkeep:

# Instalar apkeep (Rust)
cargo install apkeep

# Bajar YouTube 21.04.223
apkeep -a com.google.android.youtube@21.04.223 -d apk-pure .

Si lo bajas de APKMirror, busca la variante nodpi (universal).

2. Parchear

java -jar morphe-desktop-1.13.1-all.jar patch \
  -p patches-1.39.1.mpp \
  -o youtube-morphe-patched.apk \
  -t /tmp/tmpdir \
  yt-21.apk

Parametros:

  • -p - Archivo de parches (.mpp)
  • -o - Archivo de salida
  • -t - Directorio temporal (importante: si tenes poco espacio en /tmp, usa un directorio en el disco real)

Nota: Si tenes poco espacio en /tmp (tmpfs), usa -t para apuntar a un directorio en el disco real. YouTube parcheado usa ~1.5GB de espacio temporal.

El output va a mostrar todos los patches aplicados:

INFO: Filtering patches for com.google.android.youtube v21.04.223...
INFO: Applying 75 patches...
INFO: Applied: Hide ads
INFO: Applied: SponsorBlock
INFO: Applied: Return YouTube Dislike
INFO: Applied: Downloads
INFO: Applied: Swipe controls
...
INFO: Saved to youtube-morphe-patched.apk

3. Instalar en el celular

  1. Copia el APK parcheado al celular
  2. Desinstala YouTube original (necesario porque firma distinta)
  3. Instala el APK parcheado (habilitar “Fuentes desconocidas”)
  4. Instala MicroG-RE: https://github.com/MorpheApp/MicroG-RE/releases
  5. Abri YouTube Morphe, te va a pedir configurar MicroG
  6. Logueate con tu cuenta Google

MicroG-RE vs GmsCore

Morphe usa su propio fork de MicroG llamado MicroG-RE. Tambien funciona con el GmsCore normal de ReVanced, pero MicroG-RE esta optimizado para Morphe.

  • MicroG-RE: https://github.com/MorpheApp/MicroG-RE/releases
  • GmsCore (ReVanced): https://github.com/ReVanced/GmsCore/releases

Troubleshooting

“Disk quota exceeded” durante el parcheo

Usa -t para apuntar el directorio temporal a un disco con mas espacio:

java -jar morphe-desktop-1.13.1-all.jar patch \
  -p patches-1.39.1.mpp \
  -t /home/usuario/tmp \
  -o output.apk input.apk

“Incompatible with version X”

Tu version de YouTube no es soportada. Fijate la lista de versiones estables arriba y baje la correcta.

No me deja loguear

Asegurate de tener MicroG-RE (o GmsCore) instalado y que la optimizacion de bateria este desactivada para MicroG en Ajustes > Aplicaciones > MicroG > Bateria > Sin restricciones.
