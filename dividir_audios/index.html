1. Instalación desde cero

Estos comandos son para una instalación nueva, no hace falta repetirlos si ya tenés .venv funcionando.

sudo pacman -S --needed python ffmpeg

mkdir -p /mnt/linux2/Proyecto_80s
cd /mnt/linux2/Proyecto_80s

python -m venv .venv
source .venv/bin/activate.fish

python -m pip install --upgrade pip
python -m pip install "audio-separator[cpu]"

2. Activar el entorno existente

Cada vez que abras una terminal nueva:

cd /mnt/linux2/Proyecto_80s
source .venv/bin/activate.fish

Comprobar la instalación:

audio-separator --version
audio-separator --env_info

3. Definir el audio de entrada y carpeta de salida

Así evitás escribir las rutas largas en cada comando.

11. Consultar todos los modelos disponibles

El catálogo cambia y aparecen nuevas variantes. Podés consultar los modelos de tu instalación:

audio-separator --list_models

Buscar modelos relacionados con instrumentos:

audio-separator -l --list_filter=bass
audio-separator -l --list_filter=drums
audio-separator -l --list_filter=guitar
audio-separator -l --list_filter=piano
audio-separator -l --list_filter=vocals
audio-separator -l --list_filter=instrumental

Para obtener un catálogo JSON:

audio-separator --list_models --list_format=json

Cuando encontrás un modelo interesante, copiás su nombre exacto y lo usás así:

audio-separator "$INPUT" \
  -m "NOMBRE_EXACTO_DEL_MODELO" \
  --output_format WAV \
  --output_dir "$OUT/Nombre_del_Modelo"

12. Notas importantes

  • -m y --model_filename significan lo mismo.
  • Los modelos se descargan automáticamente la primera vez que los utilizás.
  • Cada modelo tiene sus propias salidas; no todos separan los mismos instrumentos.
  • No ejecutes varios modelos simultáneamente en tu FX-6300.
  • No sobrescribas los resultados: usá una carpeta diferente por modelo.
  • Comprobá la frecuencia de muestreo de entrada con ffprobe. Audio Separator usa 44.1 kHz por defecto; si tu archivo tiene otra frecuencia, indicá la original con --sample_rate.

Ejemplo de inspección:

ffprobe -v error -select_streams a:0 \
  -show_entries stream=sample_rate,channels \
  -of default=noprint_wrappers=1 "$INPUT"

Proyecto: separación profesional de pistas para covers de los 80

Actuás como ingeniero de audio especializado en separación de fuentes musicales mediante inteligencia artificial. Tu objetivo es preparar pistas individuales de seis canciones comerciales para que una banda pueda interpretarlas en vivo.

1. Canciones

Procesar estas seis canciones:

  1. Erasure - A Little Respect
  2. Simple Minds - Don’t You (Forget About Me)
  3. Depeche Mode - Enjoy the Silence
  4. Alphaville - Big in Japan
  5. The Cure - Just Like Heaven
  6. Eurythmics - Sweet Dreams

Son grabaciones originales de los años 80. Es importante conservar las características sonoras de cada producción.

2. Objetivo musical

La banda tiene cantante, baterista y un tecladista que toca dos teclados simultáneamente.

Se necesitan archivos WAV individuales para poder decidir posteriormente qué instrumentos se reproducen y cuáles se ejecutan en vivo.

Los instrumentos prioritarios son:

  • Batería y percusión.
  • Bajo eléctrico o sintetizado.
  • Guitarras eléctricas y acústicas.
  • Teclados y sintetizadores.
  • Pads y colchones atmosféricos.
  • Secuencias y arpegios electrónicos.
  • Efectos o capas musicales adicionales.
  • Voces, incluyendo coros cuando sea posible.

NO confundas separar seis categorías generales con separar todos los instrumentos originales. Si una canción tiene cuatro capas diferentes de sintetizador, no las etiquetes artificialmente como cuatro pistas independientes si el modelo no puede distinguirlas.

La prioridad es conseguir pistas musicales utilizables, con la menor contaminación posible.

3. Primera etapa: investigar el hardware

Antes de instalar nada, examiná el sistema:

  • Distribución y versión de Arch Linux.
  • CPU y cantidad de núcleos.
  • Memoria RAM disponible.
  • GPU, VRAM y controladores.
  • Disponibilidad real de CUDA o ROCm.
  • Espacio libre en disco.
  • Versión de Python.
  • Disponibilidad de FFmpeg.

No asumas que existe aceleración GPU. Verificá que el software realmente pueda utilizarla.

Según el hardware, elegí el mejor método de ejecución. En ausencia de aceleración compatible, utilizá CPU.

No instales dependencias globalmente con pip. Utilizá un entorno virtual Python independiente.

No utilices sudo sin necesidad ni modifiques archivos del sistema.

4. Investigar los modelos

La herramienta principal que debés evaluar es:

https://github.com/nomadkaraoke/python-audio-separator

Investigá su documentación actual y los modelos disponibles.

Instalá FFmpeg si no está disponible, y Audio Separator en un entorno virtual.

Ejecutá:

  • audio-separator –env_info
  • audio-separator –list_models –list_format=json

Investigá los modelos disponibles para:

  • Drums.
  • Bass.
  • Guitar.
  • Piano.
  • Vocals.
  • Instrumental.
  • Otros instrumentos o categorías que puedan ser útiles.

No descargues todos los modelos. Primero analizá los disponibles, su arquitectura, tamaño, requisitos y tipos de salida.

Evaluá particularmente:

  • Demucs htdemucs_6s.
  • Modelos Demucs de cuatro fuentes.
  • Modelos MDX/MDX23C.
  • BS-RoFormer.
  • MelBand RoFormer.
  • Otros modelos UVR que permitan extraer instrumentos específicos.

Importante: Demucs 6-stem es una referencia inicial, no una solución definitiva. La separación de piano puede presentar contaminación y no debe confundirse con una separación de sintetizadores.

No des por sentado que un modelo de voces/instrumental puede aislar guitarras, teclados o bajos individualmente.

5. Estrategia de separación

No ejecutes directamente un único modelo sobre las seis canciones y des por terminado el trabajo.

Primero elegí una canción piloto: Erasure - A Little Respect.

Probá distintas combinaciones de modelos y compará los resultados.

Como mínimo, buscá obtener:

  • Batería.
  • Bajo.
  • Guitarra.
  • Teclados y sintetizadores.
  • Voz.
  • Residuo musical restante.

Cuando un modelo no permita obtener una categoría específica, buscá alternativas.

Probá modelos especializados sobre las mezclas originales y, cuando tenga sentido, sobre los residuos obtenidos por otra separación. Conservá siempre cada resultado como una versión independiente.

No hagas separación recursiva indiscriminadamente: puede acumular artefactos y destruir información musical.

Para las capas de sintetizador, prestá especial atención a no confundir piano con sintetizadores, pads con guitarras o efectos con percusión.

Si no existe un modelo capaz de separar una capa concreta, informalo y conservá el material dentro de una pista residual identificada correctamente.

6. Calidad y conservación del audio

Esta parte es fundamental.

Los archivos deben:

  • Tener la misma duración que la canción original.
  • Comenzar exactamente en el mismo punto temporal.
  • Conservar el silencio inicial cuando exista.
  • Mantener la sincronización entre pistas.
  • Conservar el estéreo siempre que sea posible.
  • Mantener la frecuencia de muestreo original.
  • Exportarse en WAV sin compresión con pérdida.
  • Utilizar preferentemente PCM de 24 bits o float de 32 bits.

No cortes automáticamente los silencios iniciales o finales.

No normalices cada instrumento independientemente: esto puede destruir las relaciones de volumen originales entre las pistas.

No apliques ecualización, compresión, reverb, limitación, afinación ni efectos para intentar embellecer las separaciones.

El objetivo es obtener las fuentes separadas, no producir un remix.

Conservá intactos los archivos originales.

7. Control de calidad

Después de cada separación:

  1. Comprobá que los archivos sean reproducibles.
  2. Verificá duración, sample rate, canales y formato.
  3. Comprobá que todas las pistas estén sincronizadas.
  4. Escuchá las pistas aisladas y también junto con las demás.
  5. Identificá sonidos de otros instrumentos que hayan quedado mezclados.
  6. Detectá transitorios, artefactos y pérdidas importantes.
  7. Generá una mezcla de referencia con las pistas separadas y comparala con el original.

No consideres una separación buena simplemente porque el programa terminó sin errores.

La calidad debe evaluarse musicalmente.

Registrá qué modelo se utilizó para cada instrumento y canción, qué parámetros se emplearon y cuáles fueron las limitaciones encontradas.

9. Compatibilidad con Cubase 12

Los WAV deben poder importarse directamente en Cubase 12 como pistas individuales.

Todas las pistas de una canción deben conservar una referencia temporal común para que puedan importarse simultáneamente sin tener que corregir su posición manualmente.

Incluí un archivo README con instrucciones de importación.

Opcionalmente, prepará una mezcla de reproducción de prueba que excluya voz principal y batería, teniendo en cuenta que hay cantante y baterista en vivo. No decidas qué teclados eliminar del playback sin identificar primero qué partes puede ejecutar el tecladista.
