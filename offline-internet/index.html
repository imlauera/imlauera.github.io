Offline Internet

September 05, 2026
Internet

¡Buenísima la previsión con Wikipedia! Con eso ya tenés la base, pero te tiro varias categorías más para armar un kit offline completo:

Más ZIMs para Kiwix (no solo Wikipedia) El catálogo de Kiwix es enorme y cubre mucho más que la enciclopedia: tiene cientos de sitios curados y fuentes educativas empaquetadas para usar offline, incluyendo cosas como Project Gutenberg y TED Talks y un curso completo de programación (freeCodeCamp ofrece su currícula de JavaScript como paquete offline). Te recomiendo bajar además:

  • Wikipedia en español (la tuya está en inglés)
  • Wiktionary/Wikcionario (diccionario)
  • Wikibooks, Wikiquote, Wikivoyage (guías de viaje/vida práctica)
  • Stack Overflow y otros Stack Exchange (fundamental si programás sin internet)
  • wikiHow e iFixit (reparaciones y tutoriales prácticos, oro puro para vivir en el campo)
  • Una wiki médica tipo WikEM (primeros auxilios/medicina de emergencia)
  • Khan Academy y TED Talks

Todo esto lo buscás en library.kiwix.org (o kiwix-manage / la app Kiwix) y se pueden bajar por BitTorrent, que es más estable para archivos grandes.

Documentación técnica (clave para vos que sos de Arch)

  • arch-wiki-docs (o el wrapper archwiki-offline de AUR) te deja navegar y buscar la documentación de ArchWiki desde la terminal sin conexión, con integración a rofi/dmenu/fzf.
  • Las man pages ya las tenés localmente, pero asegurate de tener man-pages completo instalado.
  • tealdeer (tldr) — cachealo antes de cortar internet (tldr --update).
  • Zeal (equivalente libre a Dash) para tener offline la documentación de Python, Rust, C/C++, PostgreSQL, etc. en formato docset.
  • Si usás Rust: rustup component add rust-docs te deja toda la doc offline.

Un modelo de IA local (esto te va a servir muchísimo sin internet) Vale la pena instalar Ollama o llama.cpp y bajar uno o dos modelos con los pesos incluidos, para tener algo tipo “asistente” para programar, traducir o responder dudas generales sin conexión. Para uso general Qwen3 anda muy bien, DeepSeek si necesitás razonamiento más profundo, y Qwen3-Coder o Devstral si el foco es programación; si tu laptop tiene poca RAM/VRAM, Phi-4 o gpt-oss son buenas opciones livianas. Con Ollama alcanza un comando (ollama pull qwen3 por ejemplo) — pero hacelo con internet, obviamente, antes de mudarte.

Paquetes de Arch sin conexión

  • pacman -Sw <paquete> descarga sin instalar, para armar una caché grande de paquetes que probablemente vayas a necesitar (/var/cache/pacman/pkg).
  • Considerá armar un mirror local parcial de core/extra con rsync antes de irte (varias decenas de GB), y servirlo con un repo local (repo-add) — así podés reinstalar o rearmar el sistema sin internet.
  • Cloná (no solo bajes el tarball) los PKGBUILDs de AUR que más usás, por si necesitás rebuildearlos.
  • Actualizá el sistema a fondo el día antes de cortar la conexión.

Mapas offline Organic Maps u OsmAnd con los mapas de Misiones/Argentina descargados — imprescindible en el campo, con rutas, curvas de nivel, POIs, todo sin señal.

Libros y contenido

  • Una biblioteca en Calibre con ebooks que ya tengas.
  • Project Gutenberg (viene en Kiwix, pero también podés bajarlo aparte con más formatos).
  • yt-dlp para bajar antes de irte videos/podcasts/cursos que quieras conservar (documentales, canales educativos, etc.).

Salud y practicidad

  • La guía Where There Is No Doctor (Hesperian) en PDF — es la referencia clásica de salud para zonas sin acceso médico rápido.
  • Diccionarios/traductores offline: Argos Translate te permite traducir sin internet con modelos descargados.

Infraestructura en tu casa

  • kiwix-serve para levantar todo tu contenido Kiwix como servidor web en tu LAN y consultarlo desde el celu u otras compus de la casa.
  • Un buen esquema de backup local (Syncthing entre dispositivos, o Borgbackup a un disco externo) ya que perdés el backup en la nube.

¿Querés que te arme una lista de comandos concretos para dejar todo descargado y cacheado antes de cortar la conexión (paquetes, modelos de IA, ZIMs específicos)?

Prompt para OpenCode: preparar la laptop para vivir sin internet

Pegále esto tal cual a OpenCode (podés dividirlo en varias tareas si preferís ir de a poco). Está pensado para Arch Linux, con yay o paru ya instalado como AUR helper. Todo esto tiene que correr ANTES de cortar la conexión a internet.

Antes de arrancar, decile a OpenCode que:

  1. Corra df -h $HOME y te avise cuánto espacio libre hay, antes de bajar nada.
  2. Vaya avisando el tamaño de cada descarga grande antes de lanzarla (algunas pesan decenas de GB) para que puedas cancelar si no entra.
  3. Use aria2c (multi-conexión y resumible) en vez de curl/wget para todo archivo grande, y baje por torrent cuando haya .torrent disponible.

0. Instalar herramientas necesarias

sudo pacman -S --needed aria2 yt-dlp calibre zeal tealdeer kiwix-tools \
    python-pip qgis borgbackup syncthing
yay -S --needed arch-wiki-docs archwiki-offline python-argostranslate
tldr --update

1. ZIMs de Kiwix (además de la Wikipedia en inglés que ya tenés)

Instrucción para OpenCode: los nombres de archivo de Kiwix cambian de fecha en fecha, así que en vez de una URL fija, listá el directorio y agarrá el archivo más nuevo que matchee el patrón.

mkdir -p ~/offline/zim
KIWIX_BASE="https://download.kiwix.org/zim"

descargar_zim() {
  local categoria="$1" patron="$2"
  local archivo
  archivo=$(curl -s "$KIWIX_BASE/$categoria/" \
    | grep -oP 'href="\K[^"]*'"$patron"'[^"]*\.zim' | sort | tail -1)
  if [ -z "$archivo" ]; then
    echo "No encontré nada para categoria=$categoria patron=$patron, revisar manualmente en https://library.kiwix.org"
    return
  fi
  echo "Descargando $archivo"
  aria2c -x4 -s4 -c -d ~/offline/zim "$KIWIX_BASE/$categoria/$archivo"
}

descargar_zim wikipedia   "es_all_nopic"          # Wikipedia español, sin fotos (más liviana)
descargar_zim wiktionary  "es_all"                # Diccionario español
descargar_zim wikihow     "es_all"                # Tutoriales prácticos
descargar_zim ifixit      "en_all"                # Reparación de cosas
descargar_zim other       "wikem"                 # Medicina de emergencia
descargar_zim stack_exchange "stackoverflow.com_en_all_nopic"   # Pesado, fijate el tamaño antes
descargar_zim ted         "ted_multi"
descargar_zim gutenberg   "gutenberg_en_all"
descargar_zim freecodecamp "_en"

Si alguna de esas categorías/patrones ya no existe, decile a OpenCode que primero corra curl -s https://download.kiwix.org/zim/ | grep href para ver las carpetas actuales y ajuste el patrón de búsqueda.

3. Modelo de IA local (para tener un “asistente” sin internet)

curl -fsSL https://ollama.com/install.sh | sh

# Elegí según la RAM de tu laptop:
ollama pull qwen3:8b        # uso general, necesita ~8-10GB RAM libre
ollama pull qwen3-coder:7b  # para programar

Probalo con ollama run qwen3:8b antes de cortar internet, para confirmar que funciona sin conexión (Ollama no necesita red una vez que el modelo está bajado).

4. Paquetes de Arch para poder reinstalar/actualizar sin red

# Descargar (sin instalar) los paquetes que más usás, para tener la caché lista
sudo pacman -Sw --noconfirm base base-devel linux linux-firmware \
    networkmanager vim git python nodejs npm docker

# Clonar (no solo el tarball) los PKGBUILD de tus paquetes de AUR más importantes
mkdir -p ~/offline/aur
for pkg in yay paru <tus-paquetes-aur>; do
  git clone "https://aur.archlinux.org/$pkg.git" ~/offline/aur/$pkg
done

# Opcional (pesado, 30-60GB): espejo parcial de los repos oficiales para poder
# reinstalar el sistema entero sin internet
sudo pacman -S --needed rsync
rsync -avP rsync://rsync.archlinux.org/ftp_tier1_mirror/core/os/x86_64/ ~/offline/repo/core/
rsync -avP rsync://rsync.archlinux.org/ftp_tier1_mirror/extra/os/x86_64/ ~/offline/repo/extra/

Y por último, actualizá el sistema entero el día antes de irte: sudo pacman -Syu.

5. Mapas offline

mkdir -p ~/offline/mapas

  "https://download.geofabrik.de/south-america/argentina-latest.osm.pbf"

8. Traducción offline

# Bajar los paquetes de idioma para Argos Translate (necesita internet solo esta vez)
python3 -c "
import argostranslate.package
argostranslate.package.update_package_index()
available = argostranslate.package.get_available_packages()
for pkg in available:
    if pkg.from_code == 'en' and pkg.to_code == 'es':
        argostranslate.package.install_from_path(pkg.download())
    if pkg.from_code == 'es' and pkg.to_code == 'en':
        argostranslate.package.install_from_path(pkg.download())
"

Checklist final antes de cortar internet

  • df -h muestra espacio de sobra para todo lo bajado
  • sudo pacman -Syu corrido y sistema al día
  • Probaste ollama run <modelo> con el wifi apagado y funciona
  • Probaste abrir un ZIM con kiwix-serve o Kiwix Desktop sin internet
  • Backup de claves SSH/GPG (~/.ssh, ~/.gnupg) copiado a un disco externo
  • Mapas descargados también en el celular (Organic Maps/OsmAnd), no solo en la laptop

Ojo con SearXNG: es un metabuscador, no tiene índice propio — le pega a Google, Bing, DuckDuckGo, etc. por atrás. Sin internet no te devuelve nada, así que para tu caso no sirve (salvo que quieras meterte a montar algo tipo YaCy, que arma su propio índice rastreando la web, pero es mucho más peso y mantenimiento del que necesitás).

La buena noticia es que ya tenés tu Google offline sin saberlo: Kiwix. Indexa cada ZIM con Xapian (full-text real, no solo títulos) y busca en todos los ZIM cargados a la vez desde el navegador cuando corrés kiwix-serve. Y además tiene versión de terminal:

# Ya viene con kiwix-tools, que instalamos antes
kiwix-search ~/offline/zim/wikipedia_es_all_nopic.zim "fotosintesis"

Para el resto de tu contenido offline (PDFs, epubs, código, notas, lo que bajes con yt-dlp/calibre) el equivalente a “grep pero de verdad” es ripgrep-all (rga) — es ripgrep pero entiende PDF, epub, docx, sqlite, zip, subtítulos de video, etc. Y está en los repos oficiales, ni hace falta AUR:

sudo pacman -S ripgrep-all

# Busca "termino" adentro de PDFs, epubs, docx, zips, etc.
rga -i "termino" ~/offline/

Tiene caché, así que la segunda búsqueda sobre los mismos archivos es instantánea. Y se integra con fzf para búsqueda interactiva con preview en vivo (rga-fzf).

Te armé un script chiquito que junta las dos búsquedas en un solo comando, como tu “Google offline”:Para instalarlo:

chmod +x buscar-offline.sh
sudo mv buscar-offline.sh /usr/local/bin/buscar-offline

Y lo usás como buscar-offline fotosintesis — te tira primero los resultados de tus ZIMs y después lo que encuentre en el resto de tu biblioteca offline.

Un extra si querés algo más “buscador de archivos por nombre” (no contenido) para cuando sabés más o menos cómo se llama lo que buscás: sudo pacman -S plocate y después plocate <nombre> — es instantáneo porque tiene su propio índice (correr updatedb de vez en cuando para que se actualice).

#!/usr/bin/env bash
# buscar-offline: un "Google" para cuando no hay internet.
# Busca primero en todos tus ZIM de Kiwix (Wikipedia, wikiHow, StackOverflow, etc.)
# y despues en el resto de tus archivos offline (PDFs, epubs, notas, codigo) con rga.
#
# Uso: buscar-offline termino de busqueda

set -euo pipefail

QUERY="$*"
ZIM_DIR="${ZIM_DIR:-$HOME/offline/zim}"
DOCS_DIR="${DOCS_DIR:-$HOME/offline}"

if [ -z "$QUERY" ]; then
  echo "Uso: buscar-offline <termino de busqueda>"
  exit 1
fi

if command -v kiwix-search >/dev/null 2>&1 && [ -d "$ZIM_DIR" ]; then
  echo "=== Wikipedia / ZIMs ==="
  for zim in "$ZIM_DIR"/*.zim; do
    [ -e "$zim" ] || continue
    nombre=$(basename "$zim")
    resultados=$(kiwix-search "$zim" "$QUERY" 2>/dev/null | head -5 || true)
    if [ -n "$resultados" ]; then
      echo "--- $nombre ---"
      echo "$resultados"
      echo
    fi
  done
else
  echo "(kiwix-search no encontrado o no hay ZIMs en $ZIM_DIR)"
fi

if command -v rga >/dev/null 2>&1; then
  echo "=== Libros, PDFs, notas y codigo ==="
  rga -i --max-count 3 --heading "$QUERY" "$DOCS_DIR" 2>/dev/null || echo "(sin resultados)"
else
  echo "(rga no instalado: sudo pacman -S ripgrep-all)"
fi
