Setup: Smart TV + Jellyfin local en esta PC (sin buffering)

Esta PC ahora es solo el servidor de video. Las películas y series se reproducen desde el disco local a través de la red de tu casa, por eso no hay buffering ni dependencia de torrents/internet.

1. Qué se instaló

Paquete Función
jellyfin-server Servidor de medios (backend)
jellyfin-web Interfaz web del servidor
jellyfin-ffmpeg Motor de transcodificación/reproducción
sqlite Base de datos del servidor
qbittorrent-nox Cliente de torrents (headless + web UI) que descarga a la biblioteca
radarr-bin Automatiza descargas de películas (sección 9)
sonarr-bin Automatiza descargas de series (sección 9)
prowlarr-bin Buscador de torrents central (sección 9)
jackett-bin Torrent → addon local para Stremio (sección 11)
jellyseerr Web “tipo Netflix” para pedir contenidos (sección 9)

Stremio no se instaló en la PC: la PC solo sirve los archivos.

2. Disco

El disco raíz (/) estaba al 100% (986 MiB libres) y Jellyfin necesita ≥2 GiB. Se limpiaron cachés de pacman y yay (solo cachés, nada de archivos tuyos) y los datos de Jellyfin se movieron al disco grande:

/mnt/linux2/jellyfin/
├── config/   # configuración
├── data/     # base de datos
├── cache/    # caché
└── log/      # logs

3. Configuración del servicio

  • Rutas definidas en: /etc/jellyfin/jellyfin.env (apuntan a /mnt/linux2/jellyfin/*)
  • Servicio: jellyfin.service, habilitado para arrancar con el sistema e iniciado.

Comandos útiles:

sudo systemctl start jellyfin   # iniciar el servidor
sudo systemctl stop jellyfin    # detenerlo
sudo systemctl status jellyfin  # ver estado
sudo systemctl enable jellyfin  # que arranque solo al prender la PC

4. Usuario

  • Usuario: admin
  • Clave: sin clave (solo accesible desde tu red local)
  • Asistente inicial completado vía API.

5. Biblioteca de medios

  • Nombre: Media
  • Carpeta mapeada: /mnt/linux2/Media ← acá ponés tus películas/series (qBittorrent también descarga ahí, ver sección 8)
  • Nombre: Series → carpeta /mnt/linux2/Series (series del stack Radarr/Sonarr, ver sección 9)

Formato recomendado (para que saque carátulas y metadatos):

/mnt/linux2/Media/
├── Mi Pelicula (2020)/
│   └── Mi Pelicula (2020).mkv
└── Mi Serie/
    ├── Mi Serie - S01E01.mkv
    └── Mi Serie - S01E02.mkv

La carpeta Media ya existe y es tuya (puedes copiar/mover archivos con normalidad).

6. Dirección del servidor (esto usás desde la TV)

  • IP en tu red local: http://192.168.0.143:8096
  • (Alternativa vía Tailscale: http://100.91.16.10:8096 — útil si querés ver desde afuera de tu wifi)
  • El servidor escucha en todos los puertos de red locales (sin firewall activo).
  • Para entrar al panel de administración desde un navegador: http://192.168.0.143:8096/web

7. App en el Smart TV (YA INSTALADA)

La TV (192.168.0.230, modelo SWTV-20SA, Android 11) se configuró por adb:

Paso Detalle
Conexión adb adb connect 192.168.0.230:5555
App instalada Jellyfin Android TV v0.19.10 (APK oficial desde GitHub, adb install)
Servidor detectado descubierto automáticamente y cargado http://192.168.0.143:8096

Tras reboot de la TV, la app queda instalada. Si el TV no encuentra el servidor de nuevo, vuelve a escribir 192.168.0.143:8096 en “Introduce la dirección del servidor”.

(opcional) Para interactuar de nuevo con la TV por adb:

adb connect 192.168.0.230:5555

9. Stack de descarga automática (Opción B — INSTALADO Y FUNCIONANDO)

Objetivo: pedís una película o serie desde una página web tipo Netflix y se descarga sola a esta PC → pasa a Jellyfin → se ve en la TV sin buffering.

Componente Puerto URL Estado
Radarr (películas) 7878 http://192.168.0.143:7878 ✅ corriendo, raíz /mnt/linux2/Media, perfil HD-1080p, cliente qBittorrent (categoría radarr)
Sonarr (series) 8989 http://192.168.0.143:8989 ✅ corriendo, raíz /mnt/linux2/Series, perfil HD-1080p, cliente qBittorrent (categoría sonarr)
Prowlarr (buscador) 9696 http://192.168.0.143:9696 ✅ corriendo, 6 indexadores sincronizados a Radarr y Sonarr
Jellyseerr (web para pedir) 5055 http://192.168.0.143:5055 ✅ inicializado y conectado a Jellyfin + Radarr + Sonarr
qBittorrent 8080 http://192.168.0.143:8080 ✅ categorías radarr y sonarr creadas

Flujo (funciona de punta a punta):

(web) Jellyseerr → Radarr/Sonarr → Prowlarr busca → qBittorrent baja → /mnt/linux2 → Jellyfin → TV (sin buffering)

Detalles de la instalación/configuración:

  • Paquetes AUR instalados: radarr-bin (v6.3.0), sonarr-bin (v4.0.19), prowlarr-bin (v2.5.2), jackett-bin (v0.24.25), jellyseerr (v2.7.3, compilado).
  • Todos corren como el usuario local (esotericwarfare) con datos en /mnt/linux2/apps/<app> (overrides en /etc/systemd/system/*.service.d/). Reinicio automático activado.
  • Carpetas: /mnt/linux2/Media (pelis), /mnt/linux2/Series (series), descargas intermedias en /mnt/linux2/downloads/{radarr,sonarr}.
  • Calidad: HD-1080p (perfil HD-1080p), renombrado automático al estilo Jellyfin (pelis: Pelicula (Año)/Pelicula (Año) [Calidad]-Grupo; series: Serie/Season NN/Serie - SxxExx - Título).
  • Jellyfin ya tiene las 2 bibliotecas: Media → /mnt/linux2/Media y Series → /mnt/linux2/Series.
  • Indexadores configurados en Prowlarr: The Pirate Bay, YTS, Nyaa.si, LimeTorrents, Torrent9, TorrentDownloads (sincronizados automáticamente a Radarr y Sonarr). 1337x y EZTV no entran (están detrás de Cloudflare).

Cómo pedir contenido (Jellyseerr)

  1. Abrí http://192.168.0.143:5055 (loguеate con Sign in with Jellyfin: usuario admin, sin clave).
  2. Buscá la película/serie → botón REQUEST.
  3. Se descarga sola → aparece en Jellyfin (Home → Mis medios).

Nota: si Jellyseerr se reinicia, volver a habilitar librerías: curl -b <cookie> "http://127.0.0.1:5055/api/v1/settings/jellyfin/library?enable=<idMedia>,<idSeries>"

11. Notas

  • Sin buffering: la TV y la PC se comunican por tu red local; tu conexión a internet no se usa para el video (solo para carátulas/fondos la primera vez).
  • Si más adelante agregás el contenido con subtítulos hardcodeados u otro formato raro, la PC transcodifica sobre la marcha (GPU disponible: NVIDIA GTX 1050).
  • Todo el setup puede borrarse con sudo pacman -Rns jellyfin-server jellyfin-web jellyfin-ffmpeg y sudo systemctl disable --now jellyfin.
  • Stremio queda instalado en la TV para explorar y elegir contenido (no se borra).
